# 第 160 轮：Wordbook 跨词书状态过滤契约

## 审查证据

- `ReviewCard` 按 `wordId + bookCode` 存储，今日队列的 `observeNewQueue()` 也按 `wordId` 和 `bookCode` 判断是否是新词。
- `WordEntry` 是一词一条，Wordbook 搜索结果当前按词条去重展示，不是按 membership 展示。
- `filterWordsByStatus()` 在 domain 层按选中词书过滤 `ReviewCard`，再对一词一行的结果做状态过滤。
- 原测试只覆盖 `Mastered` 和 `Familiar` 的 retrievability 逻辑，缺少跨词书共享词和非选中词书卡片的回归保护。

## 方案

- 方案 A：把 Wordbook 状态过滤改成 membership 级语义。它更贴近 per-book `ReviewCard`，但当前 UI 没有展示每本词书的状态，容易让一个共享词看起来同时已学和未学。
- 方案 B：保留当前一词一行的范围语义，并补纯 domain 测试：非选中词书卡片不能影响筛选；共享词只要在选中范围内已有卡片，就不再算整词未学。改动小，契约清晰。
- 方案 C：只记录风险不补测试。成本最低，但状态过滤边界仍无回归保护。

采用方案 B。

## 修改

- `core/domain/src/test/java/com/zzz/androidvocab/core/domain/BookLearningStatsTest.kt`
  - 新增 `statusFiltersIgnoreCardsOutsideSelectedBooks()`，验证非选中词书的 due card 不会让当前词进入“待复习”，并且在当前选中词书下仍可视为“未学”。
  - 新增 `sharedWordIsNotUnlearnedWhenAnySelectedBookHasCard()`，锁定当前一词一行语义：共享词在任一选中词书已有卡片后，不再作为整词“未学”展示。
  - 测试 helper 的 `ReviewCard.id` 改为包含 `bookCode`，更贴近真实 per-book card id。
