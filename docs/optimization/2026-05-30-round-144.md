# 第 144 轮：Wordbook 状态筛选搜索刷新锁定

## 审查证据

- `feature/wordbook/src/main/java/com/zzz/androidvocab/feature/wordbook/WordbookViewModel.kt` 的 `wordsFlow` 组合了 `settingsFlow`、`query.debounce(300)` 和 `statusFilter`。
- `updateStatusFilter()` 会清空已选单词详情，已有测试覆盖这一点。
- 现有测试还没有断言切换状态筛选时，repository 会立即收到新的 `WordStatusFilter` 并用当前 query 重新搜索。

## 方案

- 方案 A：不改生产逻辑，只在 ViewModel 测试中记录 fake repository 收到的 `statusFilter`。范围最小，能锁住当前行为。
- 方案 B：重构 `wordsFlow`，把 query debounce 与筛选流拆得更显式。当前行为已正确，重构会增加无收益风险。

采用方案 A。
