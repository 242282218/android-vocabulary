# 第 108 轮：导出 checksum 自描述字段

## 审查证据

- `AndroidExportRepository` 已经在导出 JSON 写入 `checksum`，并用 SHA-256 计算排除 `checksum` 字段后的 payload。
- `AndroidExportRepositoryTest` 会复算 checksum，说明实现已有稳定回归。
- `docs/plans/2026-05-16-english-vocabulary-app-development-design.md` 的导出字段列表没有记录 `checksum`。
- 导出 payload 中也没有 `checksumAlgorithm` 和 `checksumScope`，用户拿到文件后需要读源码才知道校验算法和范围。

## 方案

- 方案 A：只补文档说明。改动最小，但导出文件本身仍不自描述。
- 方案 B：payload 增加 `checksumAlgorithm` 和 `checksumScope`，并同步测试和协议文档。改动小，保持现有 checksum 计算方式。
- 方案 C：改为严格跨语言 canonical JSON checksum。独立校验更强，但会扩大协议和实现复杂度，不适合本轮。

采用方案 B。

## 修改

- `core/database/src/main/java/com/zzz/androidvocab/core/database/AndroidExportRepository.kt`
  - 导出 payload 增加 `checksumAlgorithm = "SHA-256"`。
  - 导出 payload 增加 `checksumScope = "payload-json-excluding-checksum"`。
  - checksum 计算复用 `CHECKSUM_ALGORITHM` 常量。
- `core/database/src/test/java/com/zzz/androidvocab/core/database/AndroidExportRepositoryTest.kt`
  - 结构化导出测试断言新增两个自描述字段。
  - 既有 checksum 复算断言继续覆盖新增字段进入校验范围。
- `docs/plans/2026-05-16-english-vocabulary-app-development-design.md`
  - 导出字段列表补充 `checksumAlgorithm`、`checksumScope`、`checksum`。
  - 补充当前 checksum 范围说明。
