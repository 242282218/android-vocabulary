# 2026-05-25 持续优化第 60 轮

## 当前审查范围

本轮审查 `scripts/test/verify-vocab-assets.ps1` 的跨平台路径兼容性。该脚本会在 GitHub Actions 的 Linux runner 上通过 `pwsh` 执行，不能依赖 Windows 路径分隔符。

## 发现

脚本旧逻辑使用了 Windows 风格子路径：

```powershell
$repoRoot = Resolve-Path (Join-Path $PSScriptRoot '..\..')
$assetDir = Join-Path $repoRoot 'app\src\main\assets\vocab'
```

Windows PowerShell 下可用，但 Linux `pwsh` 不应依赖反斜杠作为路径分隔符。GitHub Actions 的第一步就是运行该脚本，如果路径解析失败，CI 会在 Gradle 质量门前失败。

## 完成项

`scripts/test/verify-vocab-assets.ps1`

- 将仓库根目录解析改为逐段 `Join-Path`。
- 将 assets 目录改为逐段 `Join-Path`：

```powershell
$repoRoot = (Resolve-Path (Join-Path (Join-Path $PSScriptRoot '..') '..')).Path
$assetDir = Join-Path (Join-Path (Join-Path (Join-Path (Join-Path $repoRoot 'app') 'src') 'main') 'assets') 'vocab'
```

- 未修改 `scripts/vocab/build-publish-safe.ps1`，因为它依赖本地外部数据源 `D:\PROJECT_ZZZZZZZZZ\Bilibili-Subtitle-Vocabulary-Extension\...`，本来就是本机发布资产构建脚本，不是 GitHub Actions 的 Linux 校验入口。
