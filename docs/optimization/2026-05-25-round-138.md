# 2026-05-25 持续优化第 138 轮

## 当前审查范围

本轮接着第 137 轮，审查 `build/bundle-smoke/` 和 `dist/` 中历史本地验证产物是否会在发布前人工归档时混入正式记录。

## 发现

当前 `build/bundle-smoke/` 中仍有历史 APK Set 中间产物：

```text
AndroidVocabulary-release-v0.1.0-1.apks
AndroidVocabulary-release-v0.1.0-1-debug-signing.apks
app-release.apks
```

这些文件不是应用商店上传产物，也不应作为正式 release 记录保存。第 137 轮已让新生成的本地验证 APK Set 使用 `build-validation` 前缀，但历史文件仍留在目录中。

## 方案

- 方案 A：脚本自动删除旧文件。目录更干净，但会破坏历史验证证据，属于不必要的破坏性操作。
- 方案 B：脚本检测并提示历史歧义文件，同时写入 metadata，方便人工归档时识别。

本轮采用方案 B。

## 完成项

- 扫描 `build/bundle-smoke/` 中的历史歧义 APK Set：
