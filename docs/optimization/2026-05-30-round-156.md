# 第 156 轮：Wordbook 长词行与等级标签间距

## 审查证据

- `WordbookRoute.WordRow()` 使用 `Row(horizontalArrangement = Arrangement.SpaceBetween)`，文本列为 `Modifier.weight(1f)`，CEFR 等级标签直接跟在右侧。
- 长英文词和长中文释义虽然会单行省略，但文本列和 CEFR 标签之间没有固定间距约束；在 360dp 小屏上视觉缓冲不足，容易显得拥挤。
- 第 155 轮已处理详情卡长文本，本轮继续处理搜索结果列表行，避免同一页面在主浏览路径上出现横向拥挤。
- 触控设计参考要求相邻可点目标之间保留误触缓冲；小屏布局参考要求长文本可控截断，不能挤压关键状态标签。

## 方案

- 方案 A：保持现状，只依赖文本省略。改动为零，但无法保证词头和 CEFR 标签之间的视觉缓冲。
- 方案 B：把 `WordRow` 的横向排列改为 `Arrangement.spacedBy(12.dp)`，继续让文本列 `weight(1f)` 省略，并补长词行 smoke。改动小，能在组件局部给标签留出固定间距。

采用方案 B。

## 修改

- `feature/wordbook/src/main/java/com/zzz/androidvocab/feature/wordbook/WordbookRoute.kt`
  - `WordRow` 横向布局从 `SpaceBetween` 改为 `spacedBy(12.dp)`。
- `app/src/androidTest/java/com/zzz/androidvocab/ScreenLayoutSmokeTest.kt`
  - 新增长词搜索结果行场景。
  - 断言长词文本和 `B2` 标签在参数化小屏 smoke 中至少保留 8dp 间距。
