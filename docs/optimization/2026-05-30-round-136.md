# 第 136 轮：统计空窗口提前返回

## 审查证据

- `core/stats/src/main/java/com/zzz/androidvocab/core/stats/OfflineStatsRepository.kt` 中 `observeReviewLoad(days, now)` 在 `days <= 0` 时最终输出空列表，但仍会计算结束日期并订阅 `statsDao.observeDueCards(end)`。
- `observeDailyActivity(days, today)` 在 `days <= 0` 时也输出空列表，但仍会订阅 `statsDao.observeDailyActivityRows(...)`。
- 空窗口本身不是有效统计请求；仓库层直接返回空 Flow 更明确，也避免无意义 DAO 查询。

## 方案

- 方案 A：在两个方法入口处对 `days <= 0` 直接 `flowOf(emptyList())`，并用 fake DAO 调用计数测试锁住“不打 DAO”。范围小，行为更清晰。
- 方案 B：保持现状，因为最终 UI 输出已经为空。改动为零，但保留无意义查询和隐式行为。

采用方案 A。

## 修改

- `core/stats/src/main/java/com/zzz/androidvocab/core/stats/OfflineStatsRepository.kt`
  - `observeReviewLoad()` 对空窗口直接返回空列表。
