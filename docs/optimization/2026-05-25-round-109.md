# 2026-05-25 持续优化第 109 轮

## 当前审查范围

本轮清理第 108 轮引入公共 helper 后留下的重复尾部输出截断逻辑。

## 发现

`scripts/lib/android-env.ps1` 已新增公共函数：

```powershell
Get-AndroidVocabularyTextTail
```

但 `scripts/test/smoke-release-bundle.ps1` 仍保留局部 `Get-TextTail`，逻辑完全重复，后续如果调整截断策略容易出现分叉。

## 方案

- 方案 A：保留局部 helper。改动最少，但重复逻辑继续存在。
- 方案 B：删除局部 `Get-TextTail`，bundletool 和 PowerShell 子脚本失败输出统一使用公共 `Get-AndroidVocabularyTextTail`。

本轮采用方案 B。

## 完成项

`scripts/test/smoke-release-bundle.ps1`

- 删除局部 `Get-TextTail`。
- `Invoke-BundleToolCommand` 和 `Invoke-PowerShellScriptCommand` 的失败异常改用 `Get-AndroidVocabularyTextTail -MaxLength 3000`。
