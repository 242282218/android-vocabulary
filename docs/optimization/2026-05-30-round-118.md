# 第 118 轮：每日新词为 0 的 UseCase 传参测试

## 审查证据

- `SettingsRoute` 已明确文案：“0 表示只复习旧词”。
- `OfflineReviewRepository.observeTodayQueue()` 会用 `(dailyNewLimit - learnedToday).coerceAtLeast(0)` 计算剩余新词；当限制为 0 时 `newItems` 为空，但 due 队列仍正常返回。
- `OfflineReviewRepositoryTest` 已有 `dailyNewLimit = 0` 时 due 队列仍返回的覆盖。
- `GetTodayQueueUseCase` 负责把设置里的 `dailyNewLimit` 传给 Repository，但 domain 单测原来没有断言 0 会原样传递。

## 方案

- 方案 A：只记录已有数据库层测试。成本最低，但 domain 组合层仍未锁住。
- 方案 B：给 `GetTodayQueueUseCase` 补传参测试，设置 `dailyNewLimit = 0` 并断言 Repository 收到 0。改动只在 domain 单测。
- 方案 C：调整 Today/Review 文案。当前 Settings 和队列表现已清晰，暂无必要扩大 UI 改动。

采用方案 B。
