# 2026-05-25 持续优化第 107 轮

## 当前审查范围

本轮审查发布构建脚本和本地验证脚本调用 `verify-vocab-assets.ps1` 时，失败信息是否带有足够阶段上下文。

## 发现

`build-release.ps1`、`build-bundle.ps1`、`verify-local.ps1` 都直接调用：

```powershell
& (Join-Path $repoRoot 'scripts\test\verify-vocab-assets.ps1')
```

`verify-vocab-assets.ps1` 自身错误信息足够具体，例如 hash mismatch、缺少 `sources.json`、publish-blocking 来源泄漏等；但调用方没有说明失败发生在发布/本地验证的 publish-safe 词库校验阶段。

## 方案

- 方案 A：不改调用方，依赖词库脚本自身错误。实现最少，但 release 失败日志缺少阶段前缀。
- 方案 B：调用方包一层 `try/catch`，保留原始 cause，并补充“发布 APK/AAB 或本地 Gradle 验证前的 publish-safe 词库校验失败”。影响面小，不改变校验逻辑。

本轮采用方案 B。
