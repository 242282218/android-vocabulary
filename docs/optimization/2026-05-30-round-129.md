# 第 129 轮：Launcher adaptive icon

## 审查证据

- `app/src/main/AndroidManifest.xml` 原本将 `android:icon` 和 `android:roundIcon` 都指向普通 `@drawable/ic_launcher` vector。
- 项目 `minSdk=26`，可以直接使用 Android adaptive icon，避免启动器圆形/方形/主题化裁剪场景表现不稳定。
- 旧 `@drawable/ic_launcher` 是单层蓝色书本图标，适合作为视觉基础，但不具备 adaptive icon 的 foreground / background 分层。

## 方案

- 方案 A：继续使用普通 vector。改动少，但发布图标在不同 launcher 形状下不可控。
- 方案 B：新增 adaptive icon 资源，manifest 指向 `@mipmap/ic_launcher` 和 `@mipmap/ic_launcher_round`。范围小，符合 Android 26+ 发布习惯。
- 方案 C：重新设计一整套 bitmap / Play Store 图标资源。视觉可控性更强，但需要更多设计验收，本轮不做。

采用方案 B。

## 修改

- `app/src/main/res/values/colors.xml`
  - 新增 `launcher_icon_background`。
- `app/src/main/res/drawable/ic_launcher_foreground.xml`
  - 新增 adaptive icon foreground vector。
- `app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml`
  - 新增 adaptive launcher icon。
- `app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml`
  - 新增 round adaptive launcher icon。
- `app/src/main/AndroidManifest.xml`
  - `android:icon` 改为 `@mipmap/ic_launcher`。
  - `android:roundIcon` 改为 `@mipmap/ic_launcher_round`。

## 验证

```powershell
. .\scripts\lib\android-env.ps1; Use-AndroidVocabularyJavaHome; .\gradlew.bat --no-daemon --console=plain :app:processDebugResources
. .\scripts\lib\android-env.ps1; Use-AndroidVocabularyJavaHome; .\gradlew.bat --no-daemon --console=plain :app:assembleDebugAndroidTest
git diff --check -- app/src/main/AndroidManifest.xml app/src/main/res/values/colors.xml app/src/main/res/drawable/ic_launcher_foreground.xml app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml app/src/main/res/mipmap-anydpi-v26/ic_launcher_round.xml
```

结果：通过；`git diff --check` 仅提示 LF/CRLF 转换，退出码为 0。
