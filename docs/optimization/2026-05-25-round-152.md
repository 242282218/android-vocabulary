# 2026-05-25 持续优化第 152 轮

## 当前审查范围

本轮接着第 151 轮，审查 release readiness 归档是否完整覆盖设备验收目录。第 151 轮已经把 readiness 读取到的父级 evidence 复制到 `build/release-readiness/evidence-*.txt`，但设备验收的 AAB 安装级 smoke 子日志仍只留在 `build/device-verification/.../` 目录。

## 发现

`verification-completed.txt` 只记录 `bundleSmokeRunMetadata=smoke-release-bundle-run.txt` 和摘要字段。如果后续只保存 `build/release-readiness/`，会缺少 AAB smoke 子流程的原始 metadata，无法直接复核 bundletool 输入、APK Set 签名类型和子流程状态。

## 方案

- 方案 A：继续只归档设备验收父日志。改动少，但 release readiness 目录不自包含。
- 方案 B：readiness 从父日志的 `bundleSmokeRunMetadata` 定位子日志，并复制为 `evidence-smoke-release-bundle-run.txt`；缺失、跳过或未使用时写 `<missing>`，避免误保留旧文件。

本轮采用方案 B。它不改变发布判定，只补齐最终证据归档。
