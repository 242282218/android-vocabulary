# 2026-05-25 持续优化第 75 轮

## 当前审查范围

本轮审查 `build-bundle.ps1` 的 `jarsigner` 验签输出和 release AAB 签名验证日志是否清楚可读。

## 发现

`build-bundle.ps1` 已经强制 `jarsigner` 使用英文输出，便于脚本稳定匹配：

```text
jar verified
jar unsigned
no manifest
```

但第 74 轮刚处理过 bundletool 的 Java 子进程输出编码问题；`jarsigner` 同样是 Java 工具，发布日志中也会打印中文项目路径，因此应同步显式 UTF-8 输出参数，降低中文路径乱码风险。

## 完成项

`scripts/release/build-bundle.ps1`

- 将 `jarsigner` 参数整理为 `$jarSignerArgs`。
- 增加 JVM 输出编码参数：

```text
-J-Dfile.encoding=UTF-8
-J-Dsun.stdout.encoding=UTF-8
-J-Dsun.stderr.encoding=UTF-8
```

- 保留英文输出参数：

```text
-J-Duser.language=en
-J-Duser.country=US
```

结果：通过。
