## 当前状态判断

第 16 轮新增了数据库 v3 migration 和 instrumentation migration test。检查验证链路后发现，`verify-local.ps1` 和 GitHub Actions 只跑 `testDebugUnitTest` 与 `assembleDebug`，不会编译 `androidTest`。这样迁移测试、Compose 布局 smoke 或设备 smoke 测试代码即使编译坏了，也可能在日常验证中漏掉。

## 对标项目可借鉴点

- Android 项目通常把 instrumentation test 分成两层质量门：CI 无设备时至少编译 test APK；有设备/模拟器时再执行 connected tests。
- 成熟开源 Android 项目的 PR 验证会覆盖 test source set 编译，避免测试代码长期失效。
- 本项目已有 migration test 和布局 smoke，至少应进入编译门。

参考：

- https://developer.android.com/studio/test
- https://developer.android.com/build/build-for-testing
