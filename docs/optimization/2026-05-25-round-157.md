# 2026-05-25 持续优化第 157 轮

## 当前审查范围

本轮接着第 156 轮，审查 release readiness 失败信息的可诊断性。上一轮已经读取归档后的 bundle smoke 子日志原文，但父日志校验和子日志原文校验仍合并在 `deviceAabVerification` 一个 requirement 中。

## 发现

当设备验收或 AAB smoke 证据不完整时，单个 `deviceAabVerification` 失败会混合父日志缺失、父日志摘要不一致、子日志原文缺失或子日志字段不一致。发布前定位问题需要回读多行 metadata。

## 方案

- 方案 A：继续合并在 `deviceAabVerification`。改动少，但失败原因不够细。
- 方案 B：保留设备父日志校验为 `deviceAabVerification`，把归档 bundle smoke 子日志原文校验拆成 `deviceBundleSmokeArchive`。

本轮采用方案 B。它不改变 readiness 门禁，只让失败列表更可诊断。

## 完成项

`scripts/test/verify-release-readiness.ps1`

- 将归档 bundle smoke 子日志原文校验拆为 `$deviceBundleSmokeArchiveReady`。
