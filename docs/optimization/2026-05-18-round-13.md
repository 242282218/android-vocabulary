# 2026-05-18 持续优化第 13 轮

## 当前状态判断

发布链路已经补到 AAB build-only smoke。本轮回到核心业务正确性。项目把 ReviewLog 作为复习与统计事实来源，这个方向正确；现有测试覆盖了同一天多次复习的 completed/new 计数、日志重放和调度失败回滚。但跨天统计还有一个关键边界缺口：同一张卡首学在前一天，隔天复习不能再计入新学。

## 对标项目可借鉴点

- SRS 项目的统计必须以 review history 为事实来源，而不是依赖可变计数器；跨天、重放、导出都要能从日志复算。
- FSRS/open-spaced-repetition 的核心数据是 review history 与卡片状态，统计展示可以缓存，但缓存必须可重建。
- AnkiDroid 等成熟离线学习项目长期依赖本地历史记录来支撑统计和迁移；本项目的 `ReviewLog` / `DailyStats` 关系应继续按“日志为真、缓存可丢弃”设计。

参考：

- https://github.com/open-spaced-repetition/free-spaced-repetition-scheduler
- https://github.com/ankidroid/Anki-Android

## 验证方案

第一次直接执行 Gradle 目标测试失败：

```powershell
.\gradlew.bat --no-daemon --console=plain :core:database:testDebugUnitTest --tests com.zzz.androidvocab.core.database.OfflineReviewRepositoryTest
```

原因：该 shell 未设置 `JAVA_HOME`。这是环境调用问题，不是测试失败。

已使用项目 helper 设置 JDK 后重跑并通过：

```powershell
. .\scripts\lib\android-env.ps1
Use-AndroidVocabularyJavaHome
.\gradlew.bat --no-daemon --console=plain :core:database:testDebugUnitTest --tests com.zzz.androidvocab.core.database.OfflineReviewRepositoryTest
```

已执行并通过总验证：

```powershell
.\scripts\test\verify-local.ps1
```

覆盖 publish-safe 词库校验、`ktlintCheck`、`detekt`、`testDebugUnitTest`、`assembleDebug`。
