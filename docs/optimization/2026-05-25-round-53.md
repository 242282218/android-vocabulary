# 2026-05-25 持续优化第 53 轮

## 当前审查范围

本轮审查发布文档与脚本产物命名的一致性，重点是 README 和 `docs/release.md` 是否仍引导使用旧的 `app-release.aab` 或泛化占位名。

## 发现

第 51、52 轮后，脚本已经收敛为版本化产物：

```text
dist\AndroidVocabulary-release-v<versionName>-<versionCode>.apk
dist\AndroidVocabulary-release-v<versionName>-<versionCode>.aab
```

但 README 和 `docs/release.md` 仍有 `<release-aab-name>` / `<release-apk-name>` 这类旧占位写法，发布验收时容易和旧的 `dist\app-release.aab` 混淆。

## 完成项

`README.md`

- 更新设备验收中已有 AAB 的 `-BundlePath` 示例。
- 明确 release APK 会以版本化文件名复制到 `dist/`。
- 明确 AAB 会以版本化文件名复制到 `dist/`。

`docs/release.md`

- 更新 release APK 输出路径。
- 更新 AAB 验签命令和归档说明。
- 更新手动 `adb install` 示例。
- 更新 APK smoke 的 `-ApkPath` 示例。
- 更新设备验收已有 AAB 的 `-BundlePath` 示例。
- 将 APK smoke 描述改为查找当前版本 release APK，而不是泛泛查找 `dist/` 或输出目录。

## 验证结果

引用一致性检查：

```powershell
rg -n "release-aab-name|release-apk-name|app-release\.aab|AndroidVocabulary-release-v<versionName>-<versionCode>" README.md docs\release.md -S
```

结果：无旧的 `<release-aab-name>` / `<release-apk-name>` / `app-release.aab` 引导残留；只保留版本化 APK/AAB 说明。

Diff 检查：

```powershell
git diff --check -- README.md docs\release.md docs\optimization\2026-05-25-round-51.md docs\optimization\2026-05-25-round-52.md
```

结果：通过，仅有 LF/CRLF 提示。
