# 2026-05-25 持续优化第 88 轮

## 当前审查范围

本轮审查 `smoke-release-apk.ps1 -ResetAppData` 的执行顺序和失败诊断。

## 发现

当前顺序是：

1. 安装 APK 或复用已安装 App。
2. 如传入 `-ResetAppData`，执行 `pm clear`。
3. 如传入 `-GrantNotificationPermission`，授予通知权限。
4. 清空 logcat 并启动 App。

这个顺序符合预期：清数据后再授予通知权限，避免 `pm clear` 把权限状态清掉；启动前清 logcat，保证后续崩溃检查只覆盖本次启动。

问题在于 `pm clear` 原本走非捕获模式，失败时只会得到裸 exit code，不一定带出 `pm` 的具体输出。

## 方案

- 方案 A：新增 `Clear-AppData`，用捕获模式执行 `pm clear`，成功时打印返回结果，失败时带 cause。改动小，不改变执行顺序。
- 方案 B：保持现状。顺序没问题，但失败诊断弱。

本轮采用方案 A。

## 完成项
