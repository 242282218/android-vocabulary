# 第 198 轮：修复本地 AAB 设备验收链路，恢复 bundletool 安装 smoke 可用

## 审查证据

- `scripts/test/verify-device.ps1`
  - 本轮目标是把设备验收从“只跑 connected tests”推进到“包含 AAB 安装级 smoke”。
- `scripts/test/smoke-release-bundle.ps1`
  - 脚本会先解析 `$script:AdbPath`，再调用 bundletool。
  - 但原实现构造 `build-apks` / `install-apks` 参数时，没有把解析出的 ADB 路径传给 bundletool。
- `scripts/test/smoke-release-apk.ps1`
  - 安装后首屏 smoke 依赖 `Wait-ForVisibleAppText()` 的固定文案 regex。
- `dist/`
  - 存在本地验证产物：
    - `AndroidVocabulary-build-validation-v0.1.0-1.aab`
  - 也存在历史 release 命名 AAB：
    - `AndroidVocabulary-release-v0.1.0-1.aab`
- 首次完整设备验收：

```powershell
. .\scripts\lib\android-env.ps1; Use-AndroidVocabularyJavaHome; .\scripts\test\verify-device.ps1 -DeviceSerial emulator-5554 -AllowUnsignedBundle -AllowDebugSigning
```

  - `connectedDebugAndroidTest` 已跑过
  - 失败阶段明确是 `bundletoolBuildApks`
  - 关键错误：
    - `Unable to determine the location of ADB. Please set the --adb flag or define ANDROID_HOME or PATH environment variable.`
- 修完 `--adb` 后，直接跑：

```powershell
. .\scripts\lib\android-env.ps1; Use-AndroidVocabularyJavaHome; .\scripts\test\smoke-release-bundle.ps1 -DeviceSerial emulator-5554 -BundlePath .\dist\AndroidVocabulary-build-validation-v0.1.0-1.aab -AllowDebugSigning
```

  - `bundletool build-apks` / `install-apks` 已成功
  - 新失败转移到安装后首屏 smoke
  - `build/apk-smoke/last-window.xml` 明确包含：
    - `今日`
    - `复习`
    - `词书`
    - `统计`
    - `设置`
    - `开始学习`
  - 说明 App 首屏已渲染，失败不是 UI 真的空白，而是 smoke 判定过于脆弱。

结论：本轮根因有两个，且都在发布验收脚本，不在 App 业务逻辑。

1. `smoke-release-bundle.ps1` 没把 ADB 路径显式传给 bundletool。
2. `smoke-release-apk.ps1` 的首屏可见文本检测依赖固定文案 regex，安装后场景下容易误判。

## 方案

- 方案 A：依赖外部环境，把 `ANDROID_HOME` 或 `PATH` 注入 bundletool 进程；继续维护固定首屏文案白名单
  - 优点：表面改动更少
  - 缺点：强依赖调用环境，首屏文案仍脆弱
- 方案 B：脚本内部显式传 `--adb`，并把首屏 smoke 判定改成“检测 UI dump 中是否存在至少一个非空文本节点”
  - 优点：更稳，不依赖外部 shell 环境，也不绑死具体文案
  - 缺点：首屏 smoke 从“特定文案”放宽成“存在可见文本”

采用方案 B。

## 修改

- `scripts/test/smoke-release-bundle.ps1`
  - `build-apks` 在 connected-device 模式下追加：
    - `--adb=$script:AdbPath`
  - `install-apks` 追加：
    - `--adb=$script:AdbPath`
- `scripts/test/smoke-release-apk.ps1`
  - `Wait-ForVisibleAppText()` 不再依赖固定中英文文案 regex。
  - 改为：
    - 先把 UI dump 归一化，移除 NUL 字符
    - 再用 `text="([^"]+)"` 抽取非空文本节点
    - 只要存在至少一个非空文本节点，就判定首屏已成功渲染

这是外科手术式修改；没有动 App 生产代码。
