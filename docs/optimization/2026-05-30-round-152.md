# 第 152 轮：Stats 全局统计范围标签补齐

## 审查证据

- 第 150 轮已让未来复习负载按选中词书过滤，第 151 轮已在 UI 中标出该图表使用“当前词书”范围。
- `StatsRoute` 中连续学习、保持率、近 7 天趋势、月历热力图、掌握分布和困难词仍来自全局日志/卡片口径，但页面没有明确标注“全部词书”。
- 设计参考强调移动端标签和数据要形成稳定层级；当前不适合为每个指标新增筛选控件，否则会增加小屏决策负担。

## 方案

- 方案 A：新增 Stats 词书筛选入口，让所有指标都可按词书切换。能力更完整，但会扩大 ViewModel、仓库和 UI 交互面。
- 方案 B：保持现有全局指标，只给全局统计 section 增加 `全部词书` detail。改动小，能立即消除“当前词书/全部词书”混合口径误解。

采用方案 B。

## 修改

- `feature/stats/src/main/java/com/zzz/androidvocab/feature/stats/StatsRoute.kt`
  - 连续学习 detail 改为 `30 天 · 全部词书`。
  - 近 7 天趋势、月历热力图、掌握分布、困难词 Top 10 增加 `全部词书` detail。
  - 复用 `ALL_BOOKS_SCOPE_LABEL`，未来负载空选择 fallback 也使用同一文案。
