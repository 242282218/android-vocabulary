# 2026-05-25 持续优化第 52 轮

## 当前审查范围

本轮继续审查 AAB 归档命名和默认选择逻辑，重点是发布留档中能否直接从文件名识别版本，以及 bundle smoke 是否会误用旧的 `app-release.aab`。

## 发现

`scripts/release/build-bundle.ps1` 旧逻辑会把 Gradle 输出的 `app-release.aab` 原名复制到 `dist/`。这有两个问题：

- `dist/app-release.aab` 不能从文件名看出 `versionName` / `versionCode`。
- 历史 AAB 并存时，`smoke-release-bundle.ps1` 旧逻辑会按 `LastWriteTime` 选择 AAB，发布验收不应依赖时间猜测。

## 完成项

`scripts/lib/android-env.ps1`

- 新增 `Get-AndroidVocabularyReleaseBundleName()`，按当前 `gradle.properties` 生成版本化 AAB 名：

```text
AndroidVocabulary-release-v<versionName>-<versionCode>.aab
```

`scripts/release/build-bundle.ps1`

- 归档到 `dist/` 时改用版本化 AAB 名。

`scripts/test/smoke-release-bundle.ps1`

- 默认 AAB 查找改为只接受 `dist/` 下当前版本的版本化 AAB。
- 找不到当前版本 AAB 时列出可用 AAB，并提示传 `-BundlePath` 或先跑 `build-bundle.ps1`。
- 继续保留显式 `-BundlePath`，用于手动验证指定产物。

## 验证结果

PowerShell 语法解析：

```powershell
$files=@('scripts/lib/android-env.ps1','scripts/release/build-bundle.ps1','scripts/test/smoke-release-bundle.ps1'); foreach ($file in $files) { $tokens=$null; $errors=$null; [System.Management.Automation.Language.Parser]::ParseFile($file, [ref]$tokens, [ref]$errors) | Out-Null; if ($errors.Count -gt 0) { Write-Error "$file parse failed"; $errors | ForEach-Object { $_.Message }; exit 1 } }; 'parse-ok'
```

结果：通过。

版本 AAB 名解析：

```powershell
. .\scripts\lib\android-env.ps1; Get-AndroidVocabularyReleaseBundleName
```

结果：`AndroidVocabulary-release-v0.1.0-1.aab`。

AAB 编译链路验证：

```powershell
.\scripts\release\build-bundle.ps1 -AllowUnsigned
```

结果：通过。脚本执行 publish-safe 词库校验、全量 `ktlintCheck`、`detekt`、`testDebugUnitTest`、`bundleRelease`，并归档到：

```text
dist\AndroidVocabulary-release-v0.1.0-1.aab
```

脚本明确警告 release signing 未配置，产物未签名或验签失败，只能用于编译链路验证，不能上传应用商店。

AAB build-only smoke：

```powershell
.\scripts\test\smoke-release-bundle.ps1 -BuildOnly -AllowDebugSigning
```

结果：通过。脚本默认使用：

```text
dist\AndroidVocabulary-release-v0.1.0-1.aab
```

并生成：

```text
build\bundle-smoke\AndroidVocabulary-release-v0.1.0-1.apks
```

Diff 检查：

```powershell
git diff --check -- scripts\lib\android-env.ps1 scripts\release\build-bundle.ps1 scripts\test\smoke-release-bundle.ps1
```

结果：通过。

## 剩余风险

- 当前验证仍使用 `-AllowUnsigned` / `-AllowDebugSigning`，不能代表正式签名发布验收。
- 当前没有在线设备，未执行 AAB 的真实 `install-apks` 和启动首屏 smoke。
- `dist/app-release.aab` 是历史产物，仍留在本地目录中；默认 smoke 已不会选它。
