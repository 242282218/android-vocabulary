# 第 146 轮：Wordbook pending query 词书切换回归

## 审查证据

- `WordbookViewModel` 的搜索请求由 `settingsFlow`、`query.debounce(300)` 和 `statusFilter` 组合生成。
- 第 145 轮修复让筛选变化读取最新 raw query，同时用 `distinctUntilChanged()` 避免重复请求。
- 词书切换同样通过 `settingsFlow` 触发搜索，属于同一类 pending query 风险；已有测试覆盖词书切换会立即刷新，但没有覆盖“query 尚未 debounce 完成”的情况。

## 方案

- 方案 A：不再补测试，认为第 145 轮生产修复已覆盖。风险是后续重构可能只保留状态筛选路径，漏掉词书切换路径。
- 方案 B：补一条词书切换 pending query 回归测试，不改生产逻辑。范围小，直接锁住同根因的第二条触发路径。

采用方案 B。
