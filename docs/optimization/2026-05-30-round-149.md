# 第 149 轮：统计回看窗口改为本地日历日

## 审查证据

- `core/common/ClockProvider.kt` 仍是唯一直接读取系统时间的入口，业务层没有散落 `Instant.now()`。
- `core/domain/ClockProviderExt.kt` 已用本地时区生成今日日期，`StatsDao` 的活动、连续学习和今日统计也按 `localDay` 聚合。
- `core/stats/OfflineStatsRepository.kt` 的 retention / 困难词窗口仍用 `now - days * 24h`，与统计页“最近 N 天”的本地日历日口径不一致；在本地午夜附近会多算或少算部分日内记录。

## 方案

- 方案 A：保留滚动 24 小时窗口，只补溢出测试。改动最少，但统计页不同模块继续使用不同日期口径。
- 方案 B：新增公共本地日历回看窗口函数，让 retention / 困难词使用“今天 + 前 N-1 天”的本地日历日 inclusive 起点。改动小，和现有 `localDay` 统计一致。

采用方案 B。

## 修改

- `core/common/src/main/java/com/zzz/androidvocab/core/common/DateMath.kt`
  - 新增 `localLookbackStart(now, days, zoneId)`，返回本地日历窗口起点；`days <= 0` 返回 `null`。
- `core/stats/src/main/java/com/zzz/androidvocab/core/stats/OfflineStatsRepository.kt`
  - retention / 困难词改用本地日历窗口。
  - `days <= 0` 时直接返回空 retention 或空困难词列表，避免无意义 DAO 查询。
- `core/common/src/test/java/com/zzz/androidvocab/core/common/DateMathTest.kt`
  - 覆盖 Asia/Shanghai 跨 UTC 边界的本地日历窗口。
- `core/stats/src/test/java/com/zzz/androidvocab/core/stats/OfflineStatsRepositoryTest.kt`
  - 覆盖 retention / 困难词传入 DAO 的窗口起点。
  - 覆盖空窗口不查 DAO。
