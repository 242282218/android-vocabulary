# 第 203 轮：为 release readiness 增加 blocker action summary

## 审查证据

- `scripts/test/verify-release-readiness.ps1`
  - 上一轮已经有 `blockerSummary`，能快速说明失败点。
  - 仍然存在的问题是：用户知道“坏在哪”，但还要继续翻 remediation 或长串 evidence，才能整理出应该先做什么。
- `build/release-readiness/release-readiness-run.txt`
  - 修改前已经有：
    - `blockerSummary=...`
  - 但没有等价的动作摘要，无法直接看出建议执行顺序。
- `scripts/test/verify-release-scripts.ps1`
  - 已覆盖 success、`releaseArtifacts` 失败、git dirty 失败场景。
  - 缺口是没有对“动作摘要”做回归保护。

## 方案

- 方案 A：新增 `blockerActionSummary`
  - 优点：改动最小，完全复用现有 readiness 判定和 remediation，不新增新文件格式
  - 缺点：仍是一行摘要，不是独立报告
- 方案 B：新增单独 summary artifact
  - 优点：可以做更完整的人读报告
  - 缺点：要维护第二套输出和回归，当前收益不够高

采用方案 A。

## 修改

- 修改 `scripts/test/verify-release-readiness.ps1`
  - 新增 `Get-BlockerActionSummaryValue`
  - 基于现有失败状态生成 `blockerActionSummary`
  - 动作摘要规则：
    - git 脏：`clean or stash the git worktree before final readiness`
    - stale release 命名产物：`replace stale release-named APK/AAB with a signed release build or archive them outside dist`
    - APK smoke 缺失：`rerun smoke-release-apk.ps1 against the current signed release APK`
    - device verification 缺失：`rerun verify-device.ps1 with the current release AAB and keep verification-completed.txt`
    - bundle smoke archive 缺失：`keep smoke-release-bundle-run.txt beside the matching device verification archive`
    - GitHub Actions evidence 缺失：`download github-actions-release-evidence for the current HEAD`
  - 将 `blockerActionSummary=...` 写入 metadata
  - 异常文案增强为：
    - `Blockers: ... Actions: ... Failed requirements: ...`
- 修改 `scripts/test/verify-release-scripts.ps1`
  - 增加静态断言，保护：
    - `function Get-BlockerActionSummaryValue`
    - `blockerActionSummary=`
    - `Actions: $blockerActionSummary.`
  - 扩充 success 夹具，要求 `blockerActionSummary=<none>`
  - 扩充 `releaseArtifacts` 失败夹具，要求动作摘要是“替换 stale release 命名产物或移出 dist”
- 扩充 git dirty 失败夹具，要求动作摘要是 `clean or stash the git worktree before final readiness`

## 验证

1. 运行：

```powershell
.\scripts\test\verify-release-scripts.ps1
```

结果：通过。

2. 运行：

```powershell
.\scripts\test\verify-release-readiness.ps1
```

结果：按预期失败，但输出已经包含动作摘要。

关键证据：

- `build/release-readiness/release-readiness-run.txt`
  - `blockerSummary=git worktree dirty (205 entries); release artifacts stale: AndroidVocabulary-release-v0.1.0-1.aab, AndroidVocabulary-release-v0.1.0-1.apk; release APK smoke evidence missing for current release APK; device AAB verification missing for current release bundle; device bundle smoke archive missing for current release bundle; GitHub Actions evidence missing for current HEAD`
  - `blockerActionSummary=clean or stash the git worktree before final readiness; replace stale release-named APK/AAB with a signed release build or archive them outside dist; rerun smoke-release-apk.ps1 against the current signed release APK; rerun verify-device.ps1 with the current release AAB and keep verification-completed.txt; keep smoke-release-bundle-run.txt beside the matching device verification archive; download github-actions-release-evidence for the current HEAD`
- 控制台异常已带：
  - `Actions: clean or stash the git worktree before final readiness; replace stale release-named APK/AAB with a signed release build or archive them outside dist; ...`

结论：readiness 现在已经同时输出：

- 机器可回放的详细 requirement evidence
- 人可快速理解的 blocker summary
- 人可直接执行的 action summary
