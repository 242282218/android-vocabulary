## 本轮发现

1. `WordbookViewModelTest` 会在 `advanceUntilIdle()` 处卡死。线程栈显示测试订阅 `uiState` 后会启动 `ClockProvider.observeNow()` 的无限分钟刷新流，虚拟时间中永远存在下一次任务。
2. release 编译通过，但 `WordbookViewModel` 使用 `Flow.debounce` 时缺少 `FlowPreview` opt-in，release Kotlin 编译会输出预览 API 警告。
3. 本地 `verify-local.ps1` 已覆盖 `assembleDebugAndroidTest`，但 GitHub Actions 的 Verify 命令没有显式包含该任务，可能漏掉非 app 模块的 androidTest APK 编译问题。

## 本轮完成项

1. 调整 `feature/wordbook` 的 ViewModel 测试同步方式：不再用 `advanceUntilIdle()` 追无限时钟流，改为 `runCurrent()` 和 `uiState.first { ... }` 等待明确状态。
2. 给 `WordbookViewModel.uiState` 增加 `FlowPreview` opt-in，消除 `debounce` 预览 API 编译警告。
3. GitHub Actions Verify 命令显式加入 `assembleDebugAndroidTest`。
4. README 的 CI 命令同步补充 `assembleDebugAndroidTest`。
