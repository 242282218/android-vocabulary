# 2026-05-25 持续优化第 90 轮

## 当前审查范围

本轮审查 AAB `jarsigner` 验签路径是否存在与 APK `apksigner` 类似的 `$ErrorActionPreference='Stop'` 提前终止问题。

## 发现

针对当前未签名 AAB 执行：

```powershell
jarsigner -verify -certs .\dist\AndroidVocabulary-release-v0.1.0-1.aab
```

脚本加上的 UTF-8 和英文输出参数生效。最小实验结果是：

```text
exit=0
no manifest.
jar is unsigned.
```

也就是说，`jarsigner` 对当前未签名 AAB 没有像 `apksigner` 那样通过 stderr 触发 PowerShell `NativeCommandError`；它返回 0，但输出文本明确标记 `no manifest` 和 `jar is unsigned`。`build-bundle.ps1` 现有逻辑已经同时检查：

- exit code 为 0。
- 输出包含 `jar verified`。
- 输出不包含 `jar unsigned`。
- 输出不包含 `no manifest`。

因此当前 AAB 未签名路径会稳定进入 `build-validation AAB, not uploadable` 分支。

## 方案

- 方案 A：不改代码，只记录验证结论。现有文本判定覆盖当前未签名 AAB。
- 方案 B：像 APK 一样临时放宽 `$ErrorActionPreference`。一致性更强，但本轮没有复现提前终止问题，暂不扩大改动。

本轮采用方案 A。

## 验证结果

`jarsigner` 当前版本化 AAB 实验：

```powershell
. .\scripts\lib\android-env.ps1; Use-AndroidVocabularyJavaHome; $jarSigner=Get-JarSigner; $target='.\dist\AndroidVocabulary-release-v0.1.0-1.aab'; $args=@('-J-Dfile.encoding=UTF-8','-J-Dsun.stdout.encoding=UTF-8','-J-Dsun.stderr.encoding=UTF-8','-J-Duser.language=en','-J-Duser.country=US','-verify','-certs',$target); try { $out=& $jarSigner @args 2>&1; "exit=$LASTEXITCODE"; "text=$($out -join ' | ')" } catch { "caught=$($_.Exception.Message)"; "lastExit=$LASTEXITCODE" }
```

结果：`exit=0`，输出包含 `no manifest` 和 `jar is unsigned`。

`jarsigner` 历史 AAB 实验：

```powershell
. .\scripts\lib\android-env.ps1; Use-AndroidVocabularyJavaHome; $jarSigner=Get-JarSigner; $target='.\dist\app-release.aab'; $args=@('-J-Dfile.encoding=UTF-8','-J-Dsun.stdout.encoding=UTF-8','-J-Dsun.stderr.encoding=UTF-8','-J-Duser.language=en','-J-Duser.country=US','-verify','-certs',$target); try { $out=& $jarSigner @args 2>&1; "exit=$LASTEXITCODE"; "text=$($out -join ' | ')" } catch { "caught=$($_.Exception.Message)"; "lastExit=$LASTEXITCODE" }
```

结果：同样 `exit=0`，输出包含 `no manifest` 和 `jar is unsigned`。

PowerShell 解析检查：

```powershell
$files=@('scripts/release/build-bundle.ps1','scripts/release/build-release.ps1','scripts/test/smoke-release-apk.ps1'); foreach ($file in $files) { $tokens=$null; $errors=$null; [System.Management.Automation.Language.Parser]::ParseFile((Resolve-Path $file), [ref]$tokens, [ref]$errors) | Out-Null; if ($errors.Count -gt 0) { Write-Error "$file parse failed"; $errors | ForEach-Object { $_.Message }; exit 1 } }; 'parse-ok'
```

结果：通过。

- 当前没有在线 Android 设备，未验证正式 AAB 安装级 smoke。
