# 第 131 轮：设计系统审美收敛与本地验证修复

## 审查证据

- `core/designsystem/src/main/java/com/zzz/androidvocab/core/designsystem/VocabColors.kt` 仍以暖米色、棕橙和低对比容器为主，和项目规则中的浅色 `#F5F5F7`、暗色 `#0B0B0F`、蓝色主行动不一致。
- `core/designsystem/src/main/java/com/zzz/androidvocab/core/designsystem/VocabTheme.kt` 在展示级标题中使用 `FontFamily.Serif` 和负字距，偏离系统字体栈与移动端可读性要求。
- 完整本地验证暴露两个质量门问题：
  - `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryTest.kt` 触发 detekt `LargeClass`。
  - `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt` 的 `DataMaintenanceCard` 触发 detekt `LongMethod`。

## 方案

- 方案 A：只收敛设计系统 token 和 typography，并按现有职责拆分测试夹具与局部 Composable。范围小，不改业务行为，能直接恢复质量门。
- 方案 B：重绘 Today/Review/Stats 等页面并顺带重构 UI 层。视觉收益更大，但回归面广，容易把发布准备阶段拖回功能开发。

采用方案 A。

## 修改

- `core/designsystem/src/main/java/com/zzz/androidvocab/core/designsystem/VocabColors.kt`
  - 将浅色背景收敛为 `#F5F5F7`，暗色背景收敛为 `#0B0B0F`。
  - 主行动色改为蓝色，并将容器、hero、错误、热力图等 token 调整为冷中性或语义色。
- `core/designsystem/src/main/java/com/zzz/androidvocab/core/designsystem/VocabTheme.kt`
  - 展示级标题统一回到 sans-serif 系统字体。
  - 移除负字距和非零字距，避免标题在小屏上显得拥挤。
- `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryTest.kt`
  - 缩小为缓存修复与 legacy 路径相关测试。
- `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryStatsAndRollbackTest.kt`
  - 新增统计、回滚、失败路径、队列排序相关测试承接原测试职责。
- `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryTestSupport.kt`
  - 新增离线复习仓库测试夹具，集中固定时钟、调度器、种子数据和失败 DAO。
- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt`
  - 将 `DataMaintenanceCard` 拆为 actions、message、error 三段，保持 UI 行为和文案不变。
