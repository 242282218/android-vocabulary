# 2026-05-25 持续优化第 123 轮

## 当前审查范围

本轮接着第 122 轮，审查 `verify-device.ps1` 是否会把 AAB smoke 自身的结构化 metadata 归档到本次设备验收日志目录。

## 发现

第 122 轮新增了：

```text
build\bundle-smoke\smoke-release-bundle-run.txt
```

但 `verify-device.ps1` 只归档了 `smoke-release-bundle.log` 和总体验证 metadata。若后续运行覆盖了全局 `build\bundle-smoke`，本次验收目录会丢失 AAB smoke 的细分信息，例如 `failureStage=resolveBundle`、`apkSetSigning=debug-signing`。

## 方案

- 方案 A：让 `smoke-release-bundle.ps1` 支持 `-LogDir`。更完整，但会扩大调用参数和实现面。
- 方案 B：`verify-device.ps1` 在执行 AAB smoke 后，把全局 `smoke-release-bundle-run.txt` 复制到本次日志目录，并在总体验证 metadata 里记录文件名。

本轮采用方案 B。

## 完成项

`scripts/test/verify-device.ps1`

- 新增 `Save-BundleSmokeRunMetadataArtifact`。
- AAB smoke 成功后复制：

```text
build\bundle-smoke\smoke-release-bundle-run.txt
```

到本次设备验收日志目录：

```text
smoke-release-bundle-run.txt
```

- AAB smoke 失败且当前阶段为 `smokeReleaseBundle` 时，也复制该 metadata。
- `verification-run.txt` / `verification-failed.txt` / `verification-completed.txt` 新增：

```text
bundleSmokeRunMetadata=<none|smoke-release-bundle-run.txt>
```
