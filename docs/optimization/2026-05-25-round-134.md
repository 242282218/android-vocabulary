# 2026-05-25 持续优化第 134 轮

## 当前审查范围

本轮接着第 133 轮，审查 GitHub Actions 中 `verify-release-scripts.ps1` 相关 PowerShell 路径是否仍有 Windows 风格子路径，避免 Ubuntu `pwsh` 把反斜杠当普通文件名。

## 发现

多个脚本仍使用类似：

```text
Join-Path $repoRoot 'scripts\test\...'
Join-Path $repoRoot 'build\tmp'
Join-Path $repoRoot 'app\build\outputs\...'
```

这些写法在 Windows 可用，但在 Linux PowerShell 中反斜杠不会稳定作为目录分隔符。由于 `verify-release-scripts.ps1` 已接入 GitHub Actions，这类路径会影响 CI 质量门。

## 方案

- 方案 A：只修 `verify-release-scripts.ps1`。改动少，但它复制执行的 smoke/device 脚本仍可能失败。
- 方案 B：给共享脚本库增加跨平台路径 helper，并修复 release 脚本回归链路会解析或调用的脚本。

本轮采用方案 B。
