# 第 200 轮：验证 build-validation 产物生成链路，确认当前阻断仍在 stale release 命名产物

## 审查证据

- `scripts/release/build-release.ps1`
  - 目标是验证 unsigned 本地 release APK 编译链路是否还能稳定产出 build-validation 产物。
- `scripts/release/build-bundle.ps1`
  - 目标是验证 unsigned 本地 release AAB 编译链路是否还能稳定产出 build-validation 产物。
- `scripts/test/verify-release-artifacts.ps1`
  - 上一轮已经增强了 stale current-version release artifact 证据。
- `dist/`
  - 运行前存在：
    - `AndroidVocabulary-release-v0.1.0-1.apk`
    - `AndroidVocabulary-release-v0.1.0-1.aab`
    - `AndroidVocabulary-build-validation-v0.1.0-1.apk`
    - `AndroidVocabulary-build-validation-v0.1.0-1.aab`
    - `app-release.aab`

## 方案

- 方案 A：继续改审计脚本
  - 优点：上下文连续
  - 缺点：如果构建链路本身已经坏了，会在错误层级上做文章
- 方案 B：先直接跑 `build-release.ps1 -AllowUnsigned` 和 `build-bundle.ps1 -AllowUnsigned`
  - 优点：先确认当前 build-validation 产物生成链路是否健康
  - 缺点：如果只是 `dist/` 污染，结果仍会是“构建成功但审计失败”

采用方案 B。

## 修改

- 本轮没有修改生产代码或脚本。
- 这轮只做构建验证和证据更新。

## 验证

1. 运行：

```powershell
.\scripts\release\build-release.ps1 -AllowUnsigned
```

结果：通过。

- `verify-vocab-assets.ps1`：通过
- `ktlintCheck detekt testDebugUnitTest assembleRelease`：通过
- 输出：
  - `build-validation APK, not release-ready: dist\AndroidVocabulary-build-validation-v0.1.0-1.apk`
  - 旧的 `AndroidVocabulary-release-v0.1.0-1.apk` 被明确保留，不会被覆盖

2. 运行：

```powershell
.\scripts\release\build-bundle.ps1 -AllowUnsigned
```

结果：通过。

- `verify-vocab-assets.ps1`：通过
- `ktlintCheck detekt testDebugUnitTest bundleRelease`：通过
- 输出：
  - `build-validation AAB, not uploadable: dist\AndroidVocabulary-build-validation-v0.1.0-1.aab`
  - 旧的 `AndroidVocabulary-release-v0.1.0-1.aab` 被明确保留，不会被覆盖

3. 回跑：

```powershell
.\scripts\test\verify-release-artifacts.ps1
```

结果：按预期失败，但失败原因已经收敛得很清楚。

关键 metadata：

- `releaseApkOlderThanBuildValidation=True`
- `releaseBundleOlderThanBuildValidation=True`
- `staleCurrentVersionArtifacts=AndroidVocabulary-release-v0.1.0-1.aab, AndroidVocabulary-release-v0.1.0-1.apk`
- `legacyDistArtifacts=app-release.aab`

最新 `dist/` 时间戳也证明了这一点：

- `AndroidVocabulary-build-validation-v0.1.0-1.apk`：2026-05-31 07:43:41
- `AndroidVocabulary-build-validation-v0.1.0-1.aab`：2026-05-31 07:29:37
- `AndroidVocabulary-release-v0.1.0-1.apk`：2026-05-25 02:25:18
- `AndroidVocabulary-release-v0.1.0-1.aab`：2026-05-25 02:29:29

结论：当前红灯不在构建脚本，而在 `dist/` 中保留的旧 release 命名产物。

## 未验证项

- 这轮没有跑 `verify-local.ps1`，因为目标是 release/build-validation 产物生成链路，不是整仓回归。
- 这轮没有跑 `verify-device.ps1`，因为设备链路在前几轮已确认；当前阻断明确转移到 `dist/` 审计层。

## 下一轮建议

  1. 增强 `verify-release-readiness.ps1`，把 `staleCurrentVersionArtifacts` 也透传到 readiness 输出

  - 或把旧 release 命名文件移出 `dist/` 后，再重跑 release 审计
