# 2026-05-25 持续优化第 131 轮

## 当前审查范围

本轮接着第 130 轮，把 release smoke / device verification 的临时回归检查沉淀成可重复脚本。

## 发现

第 126 到 130 轮使用了多段临时 PowerShell 命令验证：

- release / smoke / device 脚本 PowerShell 解析。
- `smoke-release-bundle.ps1` failure stage 映射。
- `verify-device.ps1` failure stage 映射。
- `smoke-release-apk.ps1` / `smoke-release-bundle.ps1` metadata 失败归档降级。
- `verify-device.ps1` 早期失败归档。

这些检查不需要真机，但如果只保留在优化记录里，后续脚本改动很难重复验证。

## 方案

- 方案 A：把临时命令写进文档。成本最低，但不可执行，容易漂移。
- 方案 B：新增独立回归脚本，使用临时最小仓库、fake ADB、占位 bundletool jar 复现异常路径。

本轮采用方案 B。
