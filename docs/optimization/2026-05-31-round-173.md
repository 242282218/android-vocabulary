# 第 173 轮：提醒卡需要一眼可见的状态摘要

## 审查证据

- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt`
  - 提醒卡虽然已经能区分 `MissingRuntimePermission` 和 `DisabledInSystem`，但风险只存在于正文长文案里。
  - 用户需要先读完整段说明，才能知道提醒是“需授权”还是“已暂停”。
- `core/designsystem/src/main/java/com/zzz/androidvocab/core/designsystem/Components.kt`
  - 已有 `SectionTitle(detail = ...)` 和 `VocabCard(borderColor = ...)`，足够承载简洁的状态摘要与风险边框。
- `app/src/androidTest/java/com/zzz/androidvocab/ScreenLayoutSmokeTest.kt`
  - 目前 smoke test 只锁定了正文说明，没有锁定标题级状态可见性。

结论：提醒卡的状态虽然正确，但还不够“扫一眼就懂”；当前设计系统已经有可复用能力，不需要再新增组件。

## 方案

- 方案 A：在提醒卡标题右侧增加短状态摘要，并在风险态加轻量红边。
  - 优点：最贴合现有 `SectionTitle + VocabCard` 模式，信息密度高，小屏仍稳。
  - 缺点：状态文案必须严格控制长度。
- 方案 B：在卡片正文加一枚 `VocabPill`。
  - 优点：视觉强调更强。
  - 缺点：会和已有错误文案、按钮竞争空间，卡片更拥挤。

采用方案 A。

## 修改

- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/ReminderNotificationState.kt`
  - 新增 `statusSummary(reminderEnabled)`：
    - `已开启`
    - `已关闭`
    - `需授权`
    - `已暂停`
  - 新增 `hasVisibleRisk(reminderEnabled)`，只在提醒已开启且不可用时返回 `true`。
- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt`
  - `ReminderCard` 改为用 `SectionTitle(title = "提醒", detail = ...)` 展示状态摘要。
  - 风险态时切换到轻量红边，普通态保持中性边框。
  - 将恢复说明拆成 `ReminderRecovery(...)` / `ReminderRecoveryMessage(...)`，收敛函数长度并保持行为不变。
- `feature/settings/src/test/java/com/zzz/androidvocab/feature/settings/ReminderNotificationStateTest.kt`
  - 补状态摘要和风险判定的纯逻辑测试。
- `app/src/androidTest/java/com/zzz/androidvocab/ScreenLayoutSmokeTest.kt`
  - 在缺权限场景断言 `需授权`。
  - 在系统通知关闭场景断言 `已暂停`。
