# 2026-05-25 持续优化第 70 轮

## 当前审查范围

本轮审查 `verify-device.ps1` 的设备验收日志是否能准确对应到具体 release 版本。

## 发现

发布前 checklist 要求保留 `build/device-verification/` 日志作为 release 验证记录，但 `verify-device.ps1` 默认日志目录原本只包含时间戳：

```text
build\device-verification\<yyyyMMdd-HHmmss>
```

这能定位执行时间，但不能从目录名直接看出对应的 `versionName` / `versionCode`。发布记录需要把日志、AAB、APK 和 CI 结果对应到同一个版本。

## 完成项

`scripts/test/verify-device.ps1`

- 默认日志目录改为带 release 版本：

```text
build\device-verification\v<versionName>-<versionCode>-<yyyyMMdd-HHmmss>
```

- 启动时输出：

```text
[info] version=v<versionName>-<versionCode>
```

- 新增 `verification-run.txt`，记录：
  - `startedAt`
  - `versionName`
  - `versionCode`
  - `deviceSerial`
  - `bundlePath`
  - `Skip*` / `Allow*` / `ResetAppData` / `GrantNotificationPermission` 开关
  - `usesLocalOnlyReleaseOverrides`

`docs/release.md`

- 设备验收日志路径同步为 `build/device-verification/v<versionName>-<versionCode>-<timestamp>/`。
- 补充说明 `verification-run.txt` 会记录版本号、设备 serial、AAB 路径和关键开关，正式发布记录应保留该目录。
