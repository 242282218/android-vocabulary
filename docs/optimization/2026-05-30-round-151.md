# 第 151 轮：Stats 未来负载显示当前词书范围

## 审查证据

- 第 150 轮已让未来复习负载按 `settings.selectedBooks` 过滤，和今日队列保持一致。
- `feature/stats/StatsRoute.kt` 仍只显示“未来 30 天复习负载”和“未来到期词数”，没有说明该图表已按当前选中词书过滤。
- `feature/stats/StatsViewModel.kt` 原来没有把 `selectedBooks` 暴露给 UI，导致页面无法解释负载范围。
- 设计参考要求小屏信息保持清晰层级，不为二级信息增加复杂控件；因此本轮优先补充轻量范围说明，而不是新增筛选器。

## 方案

- 方案 A：只把标题改成“当前词书未来负载”。改动最少，但用户看不到具体词书范围。
- 方案 B：ViewModel 暴露 `selectedBooks`，未来负载卡片在说明文字中显示具体词书名称。无需新增交互控件，范围清晰。

采用方案 B。

## 修改

- `feature/stats/src/main/java/com/zzz/androidvocab/feature/stats/StatsViewModel.kt`
  - `StatsUiState` 增加 `selectedBooks`。
  - ViewModel 注入 `ObserveSettingsUseCase`，把当前选中词书合入 UI 状态。
  - 避免超过当前 `combine` 重载限制，先组合 `difficultWords + settings`，再参与主状态聚合。
- `feature/stats/src/main/java/com/zzz/androidvocab/feature/stats/StatsRoute.kt`
  - 未来负载卡片标题增加 `当前词书` detail。
  - 图表说明和空状态显示具体词书范围。
- `feature/stats/src/test/java/com/zzz/androidvocab/feature/stats/StatsViewModelTest.kt`
  - 覆盖默认选中词书进入 UI 状态。
  - 覆盖多词书选择能显示到 `StatsUiState.selectedBooks`。
