# 第 158 轮：Wordbook 最后一本词书保护交互一致性

## 审查证据

- `BookSelectorCard()` 文案说明“至少保留一本词书；再次点选最后一本时会保持当前选择。”
- UI 曾在只选中一本词书时禁用该 `FilterChip`，导致用户无法执行“再次点选最后一本”的交互。
- `SettingsDataStore.updateSelectedBooks()` 已保护空集合：当取消最后一本时会保留当前选择。
- `WordbookViewModel.toggleBook()` 仍统一走设置仓库更新，因此 UI 不需要额外禁用最后一本 chip。

## 方案

- 方案 A：继续禁用最后一本已选 chip，并改文案说明“至少保留一本”。优点是无效操作不可点击；缺点是选中但禁用的视觉状态不直观，且与当前仓库保护行为重复。
- 方案 B：保持最后一本已选 chip 可点击，点击后由仓库/ViewModel no-op 保护当前选择。优点是交互和文案一致，样式稳定；缺点是一次点击不会产生可见状态变化。

采用方案 B。当前文案已经解释点击结果，且数据层已有保护。

## 修改

- `feature/wordbook/src/main/java/com/zzz/androidvocab/feature/wordbook/WordbookRoute.kt`
  - 移除最后一本已选词书的 UI 禁用判断。
  - 所有词书 chip 都保持可点击，统一调用 `onToggleBook(book)`。
- `app/src/androidTest/java/com/zzz/androidvocab/ScreenLayoutSmokeTest.kt`
  - 新增 `wordbookScreenAllowsTappingOnlySelectedBookChip()`，验证只有一本词书被选中时点击 chip 仍能触发回调。
  - 扩展 `fakeWordbookUiState()`，允许传入 `settings` 构造单词书选择场景。
