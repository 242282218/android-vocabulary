# 2026-05-25 持续优化第 44 轮

## 当前审查范围

本轮审查 Today 页首次词库导入和失败后重试入口，重点确认导入失败、重试和快速重复触发不会造成状态错乱或重复导入任务。

## 发现

Today 页已有 `isImporting` 状态，导入中会显示“正在准备词库”，失败后显示“重试导入”。但原实现中 `retryImport()` 只在新协程内部调用 `importVocabulary()` 后才设置 `isImporting = true`。失败后如果用户极快连续点击“重试导入”，可能在协程调度前启动多个导入任务。

词库导入会读 assets、校验 hash、写 Room 事务，重复启动没有必要，也会让错误/完成状态被后结束的任务覆盖。

## 完成项

`feature/today/src/main/java/com/zzz/androidvocab/feature/today/TodayViewModel.kt`

- 将导入入口收敛为 `startImport()`。
- 初始化导入和重试导入都走同一个同步 guard。
- 启动协程前立即设置 `isImporting = true` 并清空旧错误。
- 导入进行中再次触发直接返回，避免重复任务。

`feature/today/src/test/java/com/zzz/androidvocab/feature/today/TodayViewModelTest.kt`

- 保留首次导入期间 UI 处于导入中状态的测试。
- 新增失败后快速重复重试只启动一次导入任务的测试。
- Fake 词库仓库改为支持多次可控导入尝试，并记录调用次数。
