# 2026-05-25 持续优化第 91 轮

## 当前审查范围

本轮核对 release 文档与脚本输出的关键成功/阻断字符串是否一致。

## 发现

`docs/release.md` 的发布前 checklist 明确要求执行者检查：

- `[ok] release APK signature verified`
- `[ok] release AAB signature verified`
- `not release-ready`
- `not uploadable`

这些字符串如果和脚本输出不一致，会让人工验收无法按文档判断结果。

## 完成项

本轮未修改代码。核对结果：

- `scripts/release/build-release.ps1` 输出 `[ok] release APK signature verified`，与 release checklist 一致。
- `scripts/release/build-bundle.ps1` 输出 `[ok] release AAB signature verified`，与 release checklist 一致。
- APK 本地未签名验证路径输出 `build-validation APK, not release-ready`。
- AAB 本地未签名验证路径输出 `build-validation AAB, not uploadable`。
- debug signing 的 bundle smoke 输出包含 `APK Set signing=debug-signing; not release-ready`。
- `verify-device.ps1` 使用本地 override 成功时输出 `device verification passed with local-only release overrides; not release-ready`。

历史 `docs/optimization` 中保留了旧轮次当时的输出文案，不作为当前执行说明。
