# 第 210 轮：修复 mixed raw cardId 导致的缓存重复修复风险

## 审查证据

- `core/database/src/main/java/com/zzz/androidvocab/core/database/OfflineReviewRepository.kt`
  - 虽然上一轮已经把统计 SQL 改成按 `wordId + bookCode` 识别逻辑卡片，但仓库层的：
    - `repairMissingCardsFromLogs()`
    - `inspectReviewDataIntegrityInTransaction()`
    - `repairReviewDataCacheInTransaction()`
  - 仍然按 `review_logs.cardId` 分组。
- `core/database/src/main/java/com/zzz/androidvocab/core/database/Entities.kt`
  - `review_cards` 对 `(wordId, bookCode)` 有唯一索引。
  - 这意味着如果同一逻辑卡片的历史日志同时混入 canonical `cardId` 和 malformed `cardId`，repair 路径就可能：
    1. 把它们当成两张卡处理
    2. 在 upsert 时用坏 `cardId` 替换掉 canonical cache
- `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryTest.kt`
  - 之前只覆盖了“只有一个 malformed `cardId`”时可修复。
  - 没有覆盖“同一逻辑卡片混入两个 raw `cardId`”的更危险场景。

## 方案

- 方案 A：只改测试，记录当前行为
  - 优点：最小
  - 缺点：不能阻止 repair 路径写出错误 cache
- 方案 B：把仓库层 repair/integrity 也统一到逻辑卡片身份 `wordId + bookCode`
  - 优点：和上一轮 SQL 统计语义一致，真正修根因
  - 缺点：需要补 DAO 读取能力和回归测试

采用方案 B。

## 修改

- 修改 `core/database/src/main/java/com/zzz/androidvocab/core/database/ReviewDao.kt`
  - 新增：
    - `getCardByWordAndBook(wordId, bookCode)`
    - `getValidLogs()`
- 修改 `core/database/src/main/java/com/zzz/androidvocab/core/database/OfflineReviewRepository.kt`
  - 新增 `loadLogicalLogGroups()`
  - `repairMissingCardsFromLogs()` 改为按逻辑卡片分组
  - `inspectReviewDataIntegrityInTransaction()` 改为按逻辑卡片分组
  - `repairReviewDataCacheInTransaction()` 改为按逻辑卡片分组
  - 缺失 cache 时优先回写 canonical `card|book|word`
- 修改 `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryTest.kt`
  - `inspectAndRepairUseLogWordIdentityWhenCardIdIsMalformed()` 的断言改为 canonical `cardId`
  - 新增 `repairReviewDataCacheCanonicalizesMixedRawCardIdsToSingleLogicalCard()`
  - 断言同一逻辑卡片的 canonical / malformed raw `cardId` 日志最终只会修出 1 张 canonical `ReviewCard`
- 修改 `core/database/src/test/java/com/zzz/androidvocab/core/database/OfflineReviewRepositoryTestSupport.kt`
  - 给 `ReviewDao` 的测试委托实现补齐新方法

## 验证

运行：

```powershell
. .\scripts\lib\android-env.ps1
Use-AndroidVocabularyJavaHome
.\gradlew.bat --no-daemon --console=plain :core:database:testDebugUnitTest --tests "com.zzz.androidvocab.core.database.OfflineReviewRepositoryTest" --tests "com.zzz.androidvocab.core.database.OfflineReviewRepositoryStatsAndRollbackTest" --tests "com.zzz.androidvocab.core.database.DailyStatsCacheRebuildTest" --tests "com.zzz.androidvocab.core.database.AndroidExportRepositoryTest" --tests "com.zzz.androidvocab.core.database.ReviewDaoQueueTest"
```

结果：通过。

结论：现在不仅统计 SQL 按逻辑卡片认同一张卡，仓库层的 integrity / repair 也对齐到了同一语义；mixed raw `cardId` 不会再修成第二张缓存卡，也不会把 canonical cache 替换成坏 `cardId`。
