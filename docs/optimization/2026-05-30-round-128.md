# 第 128 轮：发布资源与工作区卫生复核

## 审查证据

- `app/src/main/AndroidManifest.xml`
  - 已声明 `POST_NOTIFICATIONS`。
  - `android:allowBackup="false"`，本地学习数据不会进入系统备份。
  - launcher icon 指向 `@drawable/ic_launcher`。
- `worker/src/main/res/drawable/ic_notification.xml`
  - 通知 small icon 资源存在。
- `app/proguard-rules.pro`
  - 已保留 FSRS / Lombok metadata 相关 `dontwarn`。
- 本轮 Gradle 验证后生成了 `.kotlin/`，但 `.gitignore` 未忽略，导致工作区出现额外未跟踪构建产物。

## 方案

- 方案 A：不处理 `.kotlin/`，每次本地 Gradle 运行后手动忽略。会污染发布前 `git status`。
- 方案 B：把 `.kotlin/` 加入 `.gitignore`。范围小，符合本地构建产物处理方式。

采用方案 B。

## 修改

- `.gitignore`
  - 新增 `.kotlin/`。

## 验证

```powershell
git status --short .gitignore .kotlin
git diff --check -- .gitignore
```

结果：`.kotlin/` 不再出现在状态输出；`git diff --check` 仅提示 LF/CRLF 转换，退出码为 0。

- 未做真机图标/通知截图验收，当前无在线设备。
