# 2026-05-25 持续优化第 29 轮

## 当前审查范围

本轮继续审查 release APK smoke 链路，重点是脚本的首屏可见文本断言是否和当前 Compose UI 文案一致。

## 发现

`scripts/test/smoke-release-apk.ps1` 的 `Wait-ForVisibleAppText()` 主要匹配旧英文底部导航文本：`Today|Review|Wordbook|Stats|Settings`。当前 `MainActivity` 底部导航已经是中文：`今日`、`复习`、`词书`、`统计`、`设置`。如果设备启动成功但首屏只暴露中文节点，smoke 可能误判失败。

## 方案取舍

1. 更新 smoke 脚本匹配当前中文 UI 文案，同时保留旧英文关键词。改动最小，兼容当前实现和历史输出，推荐采用。
2. 改 UI 加固定测试标记。更稳，但需要改应用代码和可访问性语义，超出本轮脚本修复范围。
3. 放宽为只检查进程存在。误报少，但会降低首屏渲染验证价值。

本轮采用方案 1。

## 完成项

- `scripts/test/smoke-release-apk.ps1`
  - 首屏文本匹配增加 `今日|复习|词书|统计|设置|正在准备词库`。
  - 保留 `开始学习|词库导入失败|Today|Review|Wordbook|Stats|Settings`，避免旧文案或错误态路径被误排除。
