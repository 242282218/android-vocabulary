# 2026-05-25 持续优化第 86 轮

## 当前审查范围

本轮审查 `smoke-release-apk.ps1` 在“应用未崩溃但首屏文本不可见”时的诊断信息。

## 发现

第 85 轮已经让首屏等待过程中能提前捕获 fatal crash。但如果应用没有崩溃，只是停在权限弹窗、空白页、错误页或非预期页面，原脚本最终只输出：

```text
App launched, but expected first-screen text was not visible within 30 seconds.
```

这个错误缺少最后一次 UI dump，无法判断设备上实际停在哪个界面。

## 方案

- 方案 A：在内存中保留最后一次窗口 XML，并在超时错误中输出最多 2000 字符的片段。改动小，直接兼容 `verify-device.ps1` 的 `smoke-release-bundle.log`。
- 方案 B：把 XML 拉到本地文件并新增日志目录参数。证据更完整，但会扩大 `smoke-release-apk.ps1` 的接口，目前只有聚合脚本才管理日志目录。

本轮采用方案 A。

## 完成项

`scripts/test/smoke-release-apk.ps1`

- 新增 `Get-TextExcerpt`。
- `Wait-ForVisibleAppText` 保存最后一次窗口 XML 文本。
- 首屏文本超时时输出：
  - 最后一次 UI dump 片段；或
  - 最后一次 UI dump 错误。
