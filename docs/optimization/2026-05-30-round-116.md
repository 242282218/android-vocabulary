# 第 116 轮：DataStore 最后一本词书保护测试

## 审查证据

- `DataStoreSettingsRepository.toggleBook()` 生产逻辑会在当前选中数大于 1 时才移除已选词书；只剩一本时会保持原选择。
- 第 115 轮已在 Wordbook UI 层把唯一已选中的 chip 禁用，但生产持久化层仍缺少专门单测覆盖。
- `DataStoreSettingsRepositoryTest` 已覆盖默认值、边界值、非法枚举和损坏 selectedBooks fallback；缺少 toggle 最后一本的行为测试。

## 方案

- 方案 A：只依赖 feature fake 测试和人工阅读生产逻辑。成本最低，但不能锁住持久化层回归。
- 方案 B：在 DataStore 单测中先选两本，移除一本，再尝试移除最后一本。覆盖完整主路径，改动只在测试。
- 方案 C：把“至少一本”规则上移到 domain use case。可复用性更强，但会改生产路径，当前已有 DataStore 保护，收益不足。

采用方案 B。

## 修改

- `core/datastore/src/test/java/com/zzz/androidvocab/core/datastore/DataStoreSettingsRepositoryTest.kt`
  - 新增 `toggleBookKeepsLastSelectedBook`。
  - 覆盖两本变一本、再次 toggle 最后一本后仍保持一本。
