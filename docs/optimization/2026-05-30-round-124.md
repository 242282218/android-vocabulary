# 第 124 轮：导出以日志视图为事实源

## 审查证据

- `AndroidExportRepository.buildExportPayload()` 输出 `dataIntegrity`、`reviewCards`、`reviewLogs`、`dailyStats`。
- `dataIntegrity` 通过 `reviewRepository.inspectReviewDataIntegrity()` 生成，失败时会降级为 `{ status: "unavailable", error: ... }`，不会阻断导出。
- `dailyStats` 直接来自 `exportDao.dailyStatsFromLogs()`，不是 `daily_stats` 缓存表。
- 现有测试已覆盖：
  - 诊断成功。
  - 检查失败时降级为 unavailable。
  - 缺失缓存时从日志派生 `dailyStats`。
- 还缺少“缓存存在但过期”时的回归测试，容易让以后误改回缓存表读取。

## 方案

- 方案 A：不改代码，只依赖现有缺失缓存测试。覆盖不够，不能锁住“事实源”语义。
- 方案 B：补一条 stale cache 回归测试，明确导出忽略过期 `daily_stats`，继续从日志视图取值。范围小，最贴合现有实现。
- 方案 C：把导出逻辑改成同时输出缓存值和日志聚合值。信息更多，但会增加导出协议复杂度，本轮没必要。

采用方案 B。
