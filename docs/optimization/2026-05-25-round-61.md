# 2026-05-25 持续优化第 61 轮

## 当前审查范围

本轮审查 GitHub Actions 中 PowerShell 脚本的调用方式，重点是 Linux runner 上执行 `verify-vocab-assets.ps1` 是否需要改成显式 `pwsh ./scripts/test/verify-vocab-assets.ps1`。

## 发现

`.github/workflows/android.yml` 当前写法是：

```yaml
- name: Verify publish-safe vocabulary assets
  shell: pwsh
  run: ./scripts/test/verify-vocab-assets.ps1
```

在 GitHub Actions 中，`shell: pwsh` 会用 PowerShell 执行 `run` 内容；`./scripts/test/verify-vocab-assets.ps1` 是 PowerShell 里的脚本执行语义，不依赖文件可执行位。

因此不需要再改为：

```yaml
run: pwsh ./scripts/test/verify-vocab-assets.ps1
```

嵌套调用 `pwsh` 不增加可靠性，反而让 shell 语义重复。

## 完成项

本轮不改代码。

保留现有 workflow 写法：

```yaml
shell: pwsh
run: ./scripts/test/verify-vocab-assets.ps1
```
