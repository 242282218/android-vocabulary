# 2026-05-25 持续优化第 66 轮

## 当前审查范围

本轮审查 AAB smoke 文档示例与 `smoke-release-bundle.ps1` 的实际签名行为是否一致。

## 发现

`smoke-release-bundle.ps1 -BuildOnly` 也会调用 bundletool 生成 APK Set，并经过签名参数检查。脚本默认要求 release signing 环境变量；当前没有正式 keystore 时，必须显式加 `-AllowDebugSigning`，否则复制文档中的 `-BuildOnly` 示例会直接失败。

原文虽然说明了没有正式 keystore 可用 `-AllowDebugSigning`，但示例命令没有给出本地调试签名写法，README 也没有说明这一点。

## 完成项

`docs/release.md`

- 在 AAB 安装级验证段补充本地调试签名示例：

```powershell
.\scripts\test\smoke-release-bundle.ps1 -BuildOnly -AllowDebugSigning
.\scripts\test\smoke-release-bundle.ps1 -DeviceSerial <serial> -AllowDebugSigning
```

- 在 `verify-device.ps1 -AllowUnsignedBundle -AllowDebugSigning` 示例后补充：成功输出 `not release-ready` 时只代表本地安装链路可用，不代表 AAB 可上传。

`README.md`

- 在 AAB smoke 示例后补充：未配置 release signing 环境时需要显式加 `-AllowDebugSigning`，该路径只做本地链路验证，不代表可发布。
