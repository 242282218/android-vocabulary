# 2026-05-25 持续优化第 87 轮

## 当前审查范围

本轮审查 `smoke-release-apk.ps1 -GrantNotificationPermission` 的可诊断性。

## 发现

脚本原逻辑直接读取 SDK 版本，并在 Android 13+ 执行：

```powershell
Invoke-AndroidDebugBridge @('shell', 'pm', 'grant', $packageName, 'android.permission.POST_NOTIFICATIONS')
```

失败时非捕获模式只抛 `adb ... failed with exit code ...`。在权限不存在、策略拒绝或包状态异常时，adb/pm 的具体输出不一定进入异常消息；Android 13 以下也没有明确 skip 日志。

## 方案

- 方案 A：新增 `Grant-PostNotificationsPermission`，解析 SDK 版本，Android 13 以下明确跳过，Android 13+ 用捕获模式执行 `pm grant` 并把 cause 包进错误。改动小，逻辑集中。
- 方案 B：保持现状，只在文档说明该参数可能失败。不能提升实际诊断质量。

本轮采用方案 A。

## 完成项

`scripts/test/smoke-release-apk.ps1`

- 新增 `Grant-PostNotificationsPermission`。
- SDK 版本解析失败时给出明确错误。
- SDK < 33 时输出跳过原因。
- SDK >= 33 时输出 SDK 版本，并在 `pm grant` 失败时带出原始 cause。
