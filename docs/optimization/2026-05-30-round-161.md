# 第 161 轮：Wordbook 详情页词书范围上下文

## 审查证据

- `WordDetail` 已包含 `memberships`，能知道一个词被哪些词书收录。
- `WordbookScreen()` 已持有 `uiState.settings.selectedBooks`，但详情卡此前只显示“词书 CET4 / CET6”，没有区分当前筛选范围和额外收录词书。
- 上一轮已明确当前 Wordbook 是一词一行语义；共享词在多词书选择下，如果详情页不说明范围，用户难以判断当前结果和额外词书归属的关系。
- 移动端设计参考要求详情和长列表有清晰返回路径、状态表达能被理解，二级信息要用轻量渐进披露而不是堆叠复杂表格。

## 方案

- 方案 A：扩展 `WordDetail`，把每本词书的学习状态一起传给 UI。信息最完整，但需要改模型、仓库和查询，范围偏大。
- 方案 B：复用现有 `WordDetail.memberships` 和 `settings.selectedBooks`，在详情页显示“当前范围 … · 另收录 …”。不展示学习状态，但能解释共享词来自哪里，改动小。
- 方案 C：保持现状，只依赖词书列表。无代码风险，但共享词详情上下文仍不足。

采用方案 B。

## 修改

- `feature/wordbook/src/main/java/com/zzz/androidvocab/feature/wordbook/WordbookRoute.kt`
  - `WordDetailCard()` 增加 `selectedBooks` 参数。
  - 新增 `wordbookScopeText()`，把 memberships 分成“当前范围”和“另收录”。
  - 详情页从“词书 CET4 / CET6”改为更明确的范围说明。
- `app/src/androidTest/java/com/zzz/androidvocab/ScreenLayoutSmokeTest.kt`
  - 新增 `wordbookScreenShowsSelectedAndExtraBooksInDetail()`，覆盖共享词详情在单选 CET4 时显示“当前范围 CET4 · 另收录 CET6”。
  - 抽出 `fakeWordMembership()`，便于构造多词书收录详情。
