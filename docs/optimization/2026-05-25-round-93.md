# 2026-05-25 持续优化第 93 轮

## 当前审查范围

本轮审查 `build-release.ps1` 的 APK 输出选择逻辑，确认不会因为 release 输出目录残留多个 APK 而误选或误阻断。

## 发现

`build-release.ps1` 当前通过共享函数获取当前版本化 APK 文件名：

```powershell
$releaseApkName = Get-AndroidVocabularyReleaseApkName
$releaseApkPath = Join-Path $releaseDir $releaseApkName
```

并只检查该文件是否存在。缺失时会列出目录中所有可用 APK：

```powershell
throw "Expected current release APK not found: $releaseApkPath. Available APKs: $availableText."
```

这和第 92 轮修正后的 AAB 逻辑一致：精确选择当前版本产物，不按 LastWriteTime 猜测，也不会因为额外 APK 文件存在而阻断。

当前实际输出目录为：

```text
app\build\outputs\apk\release\AndroidVocabulary-release-v0.1.0-1.apk
```

## 完成项

本轮未修改代码。`build-release.ps1` 已按当前版本化 APK 精确选择，符合发布留档和误用防护要求。

## 验证结果

源码检查：

```powershell
rg -n "releaseApkName|Expected current release APK|outputFileName|AndroidVocabulary-release|Get-AndroidVocabularyReleaseApkName|outputs\\apk\\release" scripts app docs README.md -S
```

结果：`build-release.ps1`、`smoke-release-apk.ps1` 和文档均使用当前版本化 APK 名称。

当前 release APK 输出目录检查：

```powershell
Get-ChildItem .\app\build\outputs\apk\release -Filter '*.apk' -File -ErrorAction SilentlyContinue | Select-Object Name,FullName,Length,LastWriteTime
```

结果：当前输出目录包含 `AndroidVocabulary-release-v0.1.0-1.apk`。
