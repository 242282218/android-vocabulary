# 第 111 轮：Settings 词库来源列表小屏可读性

## 审查证据

- `SettingsRoute.SourceRow` 原来把来源名称和许可证状态横排；名称强制 1 行，长状态 pill 会和名称争抢小屏宽度。
- 许可证和说明原来拼成一段 `license / notes`，扫描时不容易分辨字段。
- publish-blocking 提示原来是单句红色文本，没有明确说明“不进入发布词库”的结果。
- `SettingsViewModelTest` 原来没有覆盖 `observeSourceInfo()` 到 `uiState.sources` 的透传。
- `ui-ux-pro-max` 与设计参考都强调小屏长文本应分层展示，状态不能只靠颜色。

## 方案

- 方案 A：只把名称改为 2 行。最小，但状态 pill 和说明文本仍挤在同一层级。
- 方案 B：把来源行改成纵向层级：名称、状态 pill、许可证、说明、发布阻断提示分行；补 sources 透传测试。小步且适合小屏。
- 方案 C：做可展开详情和外链入口。更完整，但会增加交互和外链处理，超出本轮。

采用方案 B。

## 修改

- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt`
  - `SourceRow` 改为纵向信息层级。
  - 来源名称允许 2 行省略。
  - 许可证独立显示为 `许可证：...`。
  - 来源说明独立显示，最多 3 行。
  - 发布阻断提示改为“发布阻断：仅保留许可证说明，不进入发布词库。”
- `feature/settings/src/test/java/com/zzz/androidvocab/feature/settings/SettingsViewModelTest.kt`
  - 新增 `settingsStateIncludesVocabularySources`。
  - `FakeVocabularyRepository` 支持注入 sources。
