# 第 176 轮：数据维护需覆盖 daily_stats 缓存一致性

## 审查证据

- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt`
  - 数据维护卡文案写的是“检查复习记录、卡片缓存和日统计缓存的一致性”。
- `core/database/src/main/java/com/zzz/androidvocab/core/database/OfflineReviewRepository.kt`
  - 之前的 `inspectReviewDataIntegrityInTransaction()` 只检查 `review_logs -> review_cards`，没有检查 `daily_stats`。
  - `repairReviewDataCache()` 也不会重建 `daily_stats`。
- `core/database/src/test/java/com/zzz/androidvocab/core/database/DailyStatsCacheRebuildTest.kt`
  - 已证明 `daily_stats` 可以脏、缺失，并且能从 `review_daily_stats` 全量重建。

结论：设置页承诺的“学习缓存一致性”与实际检查范围不一致，`daily_stats` 脏数据不会被报告，也不会被修复。

## 方案

- 方案 A：只在修复时无条件重建 `daily_stats`。
  - 优点：实现小。
  - 缺点：检查报告仍然失真，用户看不到统计缓存问题。
- 方案 B：把 `daily_stats` 缺失/不一致纳入 `ReviewDataIntegrityReport`，修复时按 issue 触发原子重建。
  - 优点：报告、修复、导出、设置页文案语义一致。
  - 缺点：需要同步 model、repository、导出和测试。

采用方案 B。

## 修改

- `core/model/src/main/java/com/zzz/androidvocab/core/model/ReviewModels.kt`
  - 为 `ReviewDataIntegrityReport` 新增：
    - `dailyStatsDays`
    - `missingDailyStatsCount`
    - `inconsistentDailyStatsCount`
  - `repairableIssueCount` / `issueCount` 现在会把统计缓存问题计入。
- `core/database/src/main/java/com/zzz/androidvocab/core/database/StatsDao.kt`
  - 新增 `dailyStats()` 与 `dailyStatsFromLogsRows()` 快照查询，供 integrity inspect 对比缓存与日志聚合结果。
- `core/database/src/main/java/com/zzz/androidvocab/core/database/OfflineReviewRepository.kt`
  - `inspectReviewDataIntegrityInTransaction()` 新增 `daily_stats` 与 `review_daily_stats` 的按天对比。
  - 缺失天数记入 `missingDailyStatsCount`。
  - 值不一致或多余脏行记入 `inconsistentDailyStatsCount`。
  - `repairReviewDataCache()` 在存在统计缓存问题时调用 `statsDao.rebuildDailyStatsCache(now)` 原子重建。
  - `repairedCount` 现在会把被修复的统计日数一起计入。
- `core/database/src/main/java/com/zzz/androidvocab/core/database/AndroidExportRepository.kt`
  - 导出的 `dataIntegrity` JSON 增加统计缓存诊断字段。
- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsViewModel.kt`
  - 仅当存在统计缓存问题时，在数据维护结果消息里追加“日统计 X 天：缺失 Y，不一致 Z”。
  - 无统计问题时保留原有文案，避免无意义 UI 回归。
- `feature/settings/src/main/java/com/zzz/androidvocab/feature/settings/SettingsRoute.kt`
  - 数据维护说明文案改为明确包含日统计缓存。
