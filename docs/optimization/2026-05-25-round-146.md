# 2026-05-25 持续优化第 146 轮

## 当前审查范围

本轮接着第 145 轮，审查 AAB 安装级验收是否绑定具体 release AAB 文件。上一轮已经让 APK smoke metadata 写入 `apkSha256`，但设备验收和 AAB smoke 仍只记录路径与版本化文件名，不能防止同名 AAB 被替换后证据链仍误判通过。

## 发现

`build/device-verification/.../verification-completed.txt` 和 `build/bundle-smoke/smoke-release-bundle-run.txt` 缺少输入 AAB 的 SHA-256。`verify-release-readiness.ps1` 只能判断设备验收使用了当前版本化 AAB 文件名，不能确认它与 release artifact 审计记录中的 `releaseBundleSha256` 是同一个文件。

## 方案

- 方案 A：继续只校验 AAB 路径和版本化文件名。改动少，但不能防止同名文件替换。
- 方案 B：AAB smoke 和设备验收 metadata 都写入输入 AAB 的 SHA-256，release readiness 要求设备验收 `bundleSha256` 与 release artifact metadata 中的 `releaseBundleSha256` 一致。

本轮采用方案 B。它不改变安装流程，只增强发布证据绑定。

## 完成项

`scripts/test/smoke-release-bundle.ps1`

- 新增 `Get-BundleSmokeSha256Value`。
- metadata 增加 `bundleSha256`。
- AAB 路径未解析或缺失时分别写入 `<unresolved>` / `<missing>`。

`scripts/test/verify-device.ps1`

- 新增 `Get-ResolvedBundleSha256`。
- `verification-run.txt` / `verification-completed.txt` / `verification-failed.txt` 增加 `bundleSha256`。
- `-SkipBundleSmoke` 时写入 `bundleSha256=<not used>`，避免跳过 AAB 安装验收被误判为完整发布证据。

`scripts/test/verify-release-readiness.ps1`

- 读取设备验收 metadata 中的 `bundleSha256`。
- `deviceAabVerification` 要求：
  - `runStatus=completed`
  - 当前 `versionName` / `versionCode`
  - `usesLocalOnlyReleaseOverrides=False`
  - `bundlePathMatchesCurrentVersionedName=True`
  - `bundleSmokeApkSetSigning=release-signing`
  - `bundleSha256` 是 64 位小写 SHA-256
  - `bundleSha256` 等于 release artifact metadata 中的 `releaseBundleSha256`
- readiness metadata 增加 `deviceBundleSha256`。

`scripts/test/verify-release-scripts.ps1`

- 增加 AAB smoke 和设备验收 SHA-256 metadata 写入的源码结构回归断言。
- 增加 readiness 对设备 AAB SHA-256 比对逻辑的源码结构回归断言。
- 更新 AAB smoke / device early failure metadata 回归，要求失败归档包含合理的 `bundleSha256` 降级值。

文档同步：

- `README.md`
- `docs/release.md`

## 剩余风险

- 当前没有在线 Android 设备，未验证新版 `verify-device.ps1` / `smoke-release-bundle.ps1` 正向成功 metadata。
- 当前没有正式 release signing 环境，未验证 readiness 正向成功路径。
- `verify-release-readiness.ps1` 仍只读取父级 `verification-completed.txt` 的 `bundleSha256`，尚未交叉校验子级 `smoke-release-bundle-run.txt` 中 bundletool 实际消费的 AAB hash。
