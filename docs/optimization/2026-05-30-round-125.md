# 第 125 轮：统计仓储事实源复核

## 审查证据

- `OfflineStatsRepository.observeTodayStats()` 读取 `statsDao.observeDailyStatsFromLogs()`，不是 `daily_stats` 缓存表。
- `observeBookStats()` 读取 `observeBookTotals()` + `observeValidReviewCards()`。
- `observeReviewLoad()`、`observeDailyActivity()`、`observeDifficultWords()`、`observeRetentionStats()` 也都通过视图、日志或卡片表派生，不直接读 `daily_stats` 缓存。
- `rebuildDailyStatsCache()` 是显式维护接口，不在普通统计读取路径里参与计算。

## 方案

- 方案 A：给统计仓储补一组 stale cache 回归测试。能更直接锁语义，但需要引入额外数据库场景，本轮收益不高。
- 方案 B：保留现状，只用现有统计单测复核公开读取路径。范围最小，且代码已经符合事实源要求。

采用方案 B，本轮不改代码。
