# 2026-05-25 持续优化第 77 轮

## 当前审查范围

本轮审查 `smoke-release-apk.ps1 -SkipInstall` 的语义是否会被误读为完整 APK smoke。

## 发现

`-SkipInstall` 会跳过：

- APK 文件签名校验。
- APK 安装。

它只对目标设备上已经安装的 App 做启动、首屏文本和崩溃日志检查。原脚本最后仍输出：

```text
[ok] release APK smoke test passed
```

这容易被误读成完整 release APK smoke 已通过。`smoke-release-bundle.ps1` 复用这个参数是合理的，因为 AAB 已经先通过 bundletool 安装；但直接执行 `smoke-release-apk.ps1 -SkipInstall` 时必须清楚其边界。

## 完成项

`scripts/test/smoke-release-apk.ps1`

- `-SkipInstall` 分支输出改为：

```text
[info] skipping APK signature verification and install; using already installed app
```

- 最终成功文案按路径区分：

```text
[ok] installed app launch smoke passed; APK signature verification and install were skipped
[ok] release APK smoke test passed
```

`docs/release.md`

- 在 APK 安装验证段补充：`-SkipInstall` 只用于 AAB 已通过 bundletool 安装后的复用检查，或手动确认目标设备已安装正确版本时的启动检查。
- 明确 `-SkipInstall` 会跳过 APK 文件签名校验和安装，不能单独代表完整 release APK smoke。
