# 2026-05-25 持续优化第 126 轮

## 当前审查范围

本轮接着第 125 轮，审查 `smoke-release-bundle.ps1` 在异常路径中保存 metadata 时，是否会被 metadata 自身的版本读取失败掩盖原始错误。

## 发现

`Save-BundleSmokeRunMetadata` 会读取：

```text
androidVocab.versionName
androidVocab.versionCode
Get-AndroidVocabularyReleaseBundleName
```

这些读取在正常仓库中没有问题，但如果脚本在临时目录、损坏仓库或缺失 `gradle.properties` 的环境里失败，catch 中再次调用 metadata 保存会二次失败，只留下 warning，无法写出结构化失败记录。

## 方案

- 方案 A：只在 catch 外提前解析版本号。主路径简单，但早期失败仍可能没有字段值。
- 方案 B：给 metadata 保存函数使用安全取值 helper，读取失败时写 `<unresolved>`，其余验证流程不变。

本轮采用方案 B。

## 完成项

`scripts/test/smoke-release-bundle.ps1`

- 新增 `Get-BundleSmokeMetadataValue`。
- `Save-BundleSmokeRunMetadata` 中版本号和预期 AAB 名称读取失败时降级为 `<unresolved>`。
- 当预期 AAB 名称不可解析时：

```text
bundlePathMatchesCurrentVersionedName=<unknown>
```
