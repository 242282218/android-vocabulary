# 第 143 轮：Wordbook 词书切换搜索刷新锁定

## 审查证据

- `feature/wordbook/src/main/java/com/zzz/androidvocab/feature/wordbook/WordbookViewModel.kt` 的 `wordsFlow` 由 `settingsFlow`、`query.debounce(300)`、`statusFilter` 组合后触发搜索。
- 搜索词输入需要 debounce；但词书选择变化是显式筛选条件变化，应立即用当前 query 重新查询，不应等待下一次输入防抖。
- 第 142 轮已锁定快速输入只查询最终 query，但还缺少“切换词书立即刷新当前搜索”的回归测试。

## 方案

- 方案 A：不改生产逻辑，只补 ViewModel 测试，在 fake repository 中记录搜索使用的 `bookCodes`。范围小，能锁住现有组合流语义。
- 方案 B：调整生产流，把 query debounce 与 settings/status 分开组合。改动更大，当前实现已满足行为，暂不扩大风险。

采用方案 A。
