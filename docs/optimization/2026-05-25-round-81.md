# 2026-05-25 持续优化第 81 轮

## 当前审查范围

本轮审查 `smoke-release-bundle.ps1` 的成功尾部日志是否能独立表达 APK Set 签名性质和可发布边界。

## 发现

脚本在 bundletool 构建前已经输出：

```text
[info] APK Set signing=<release-signing|debug-signing>
```

但成功尾部只有 debug signing 路径会明确 `not release-ready`，release signing 路径只输出 `release AAB smoke test passed`。如果发布记录只截取日志尾部，仍需要回翻前文确认 APK Set 签名类型。

## 完成项

`scripts/test/smoke-release-bundle.ps1`

- build-only 成功尾部改为：
  - `APK Set signing=debug-signing; not release-ready`
  - `APK Set signing=release-signing`
- 完整 AAB smoke 成功尾部改为：
  - `APK Set signing=debug-signing; not release-ready`
  - `APK Set signing=release-signing`

这样日志尾部即可判断当前验收是正式签名路径，还是本地 debug signing 验证路径。
