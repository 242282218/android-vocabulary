# 第 142 轮：Wordbook 搜索 debounce 语义锁定

## 审查证据

- `feature/wordbook/src/main/java/com/zzz/androidvocab/feature/wordbook/WordbookViewModel.kt` 对搜索词使用 `query.debounce(300)` 后再调用 `SearchWordsUseCase`。
- `SearchWordsUseCase` 会随时间刷新重新查询，供 due/status 过滤使用。
- `AssetVocabularyRepository.searchWords()` 会 trim 并 escape LIKE 通配符，空词书选择会回退全词书。
- 现有 Wordbook 测试覆盖了加载、筛选清空详情、保留最后词书，但没有锁住“快速输入只查最终 query”的防抖语义。

## 方案

- 方案 A：不改生产逻辑，只补 ViewModel 测试，记录快速输入 `a -> ab` 时 300ms 内不查库，最终只用 `ab` 查询。范围小，锁住体验和性能语义。
- 方案 B：把 debounce 移到 UseCase 或 Repository。会扩大职责变更，且当前 ViewModel 层处理 UI 输入节流是合理边界。

采用方案 A。
