# 2026-05-25 持续优化第 139 轮

## 当前审查范围

本轮接着第 138 轮，审查 `dist/` 中历史 release 命名 APK/AAB 是否会被人工误认为可发布产物。

## 发现

当前 `dist/` 中同时存在：

```text
AndroidVocabulary-build-validation-v0.1.0-1.apk
AndroidVocabulary-build-validation-v0.1.0-1.aab
AndroidVocabulary-release-v0.1.0-1.apk
AndroidVocabulary-release-v0.1.0-1.aab
app-release.aab
```

第 135 轮已经避免新的 `-AllowUnsigned` 覆盖 release 命名文件，但历史 release 命名 APK/AAB 仍存在。单看文件名无法判断它们是否真实签名。

## 方案

- 方案 A：自动删除历史 release 命名产物。更干净，但破坏历史验证证据，且可能误删用户手工保留的文件。
- 方案 B：增加只读审计脚本，验证当前版本 release 命名 APK/AAB 是否真实验签，并把状态写入 metadata。

本轮采用方案 B。

## 完成项

新增 `scripts/test/verify-release-artifacts.ps1`：

- 只读检查 `dist/AndroidVocabulary-release-v<versionName>-<versionCode>.apk`。
- 只读检查 `dist/AndroidVocabulary-release-v<versionName>-<versionCode>.aab`。
- APK 使用 `apksigner verify --verbose`。
- AAB 使用 `jarsigner -verify -certs`，并要求输出包含 `jar verified` 且不包含 `jar unsigned` / `no manifest`。
- 写入 `build/release-artifacts/release-artifacts-run.txt`。
- 记录 build-validation 产物是否存在。
- 记录 `app-release.aab` 等历史或非当前 release 命名产物。
- 不删除、不移动任何 `dist/` 文件。

`scripts/test/verify-release-scripts.ps1`

- 将 `verify-release-artifacts.ps1` 纳入 PowerShell 解析回归。
- 增加 metadata 字段存在性回归。

文档同步：

- `README.md`
- `docs/release.md`
