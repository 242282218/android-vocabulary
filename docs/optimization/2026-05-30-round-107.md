# 第 107 轮：导出证据链容错回归覆盖

## 审查证据

- `AndroidExportRepository` 导出 `vocabularyManifest`、`latestImportRun`、`dataIntegrity`、`reviewCards`、`reviewLogs`、`dailyStats` 和 `checksum`。
- `ExportDao.reviewCards()` 与 `ExportDao.reviewLogs()` 都通过有效 `wordbook_memberships` 过滤，避免导出孤儿卡片和孤儿日志。
- `dailyStats` 从 `review_daily_stats` 视图派生，不依赖可能缺失或过期的 `daily_stats` 缓存。
- 已有测试覆盖结构化 JSON、缓存缺失时从日志派生统计、孤儿行排除、坏的 importRun `bookCountsJson` 原样保留。
- 缺口：坏的 `source_manifest.json` 是否保留为字符串、完整性检查失败是否写入 `dataIntegrity.status=unavailable`，都缺少回归证据。

## 方案

- 方案 A：只记录缺口。零改动，但导出证据链降级行为没有测试保护。
- 方案 B：补 `AndroidExportRepositoryTest`，锁住来源 manifest 坏值保留和完整性检查失败降级。只加测试，不改变导出行为。
- 方案 C：导出时遇到 manifest 或完整性检查异常直接失败。证据更严格，但会阻断用户取回数据，发布前风险更高。

采用方案 B。
