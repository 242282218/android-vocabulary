# 第 147 轮：Wordbook 清空筛选即时搜索回归

## 审查证据

- `WordbookRoute` 的“清空筛选”会连续调用 `onQueryChange("")` 和 `onStatusFilterChange(WordStatusFilter.All)`。
- 如果当前 query 已经 debounce 完成，而清空 query 尚未 debounce 完成，状态筛选重置必须立即用空 query 搜索，不能短暂使用旧 query。
- 第 145 轮生产修正已覆盖该组合，本轮补贴近 UI 行为的回归测试。

## 方案

- 方案 A：依赖第 145 轮 pending query 测试。覆盖的是同类机制，但不直观对应“清空筛选”用户路径。
- 方案 B：补 ViewModel 层连续调用测试，模拟 UI 清空筛选行为。范围小，能直接锁住真实入口。

采用方案 B。

## 修改

- `feature/wordbook/src/test/java/com/zzz/androidvocab/feature/wordbook/WordbookViewModelTest.kt`
  - 新增 `clearingQueryAndStatusFilterSearchesEmptyQueryImmediately`。
  - 断言连续清空 query 和状态筛选会立即用空 query 搜索，且 debounce 到期不重复发相同请求。
