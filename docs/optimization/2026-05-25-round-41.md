## 发现

相邻版本迁移测试已经覆盖：

- v1 -> v2：`word_entries.cefrRank` 从 INTEGER 迁移为 REAL。
- v2 -> v3：`review_logs` 增加 `stateAfter`、`dueAtAfter`。
- v3 -> v4：`vocabulary_import_runs` 增加 `assetFingerprint`。
- v4 -> v5：创建 `valid_review_logs` 和 `word_card_view` 两个 Room view。

但缺少从旧版本一路升级到最新版本的端到端测试。真实用户升级时会一次应用完整 migration list，分段测试通过不等于整条链路一定被覆盖。
