# 2026-05-25 持续优化第 154 轮

## 当前审查范围

本轮接着第 153 轮，审查 release readiness 输出的人工复核可读性。上一轮已经为每个归档 evidence 记录 SHA-256，但字段分散在多行，发布前人工核对时仍容易漏看。

## 发现

`release-readiness-run.txt` 中有五组 `*EvidenceArchive` 和 `*EvidenceArchiveSha256` 字段，但没有一行总览。发布复核需要逐行找字段，尤其在失败路径下容易忽略设备父日志或 bundle smoke 子日志缺失。

## 方案

- 方案 A：继续保留分散字段。零额外逻辑，但人工复核成本较高。
- 方案 B：保留分散字段，同时新增稳定顺序的 `evidenceArchives=` 汇总清单。

本轮采用方案 B。它不改变 readiness 判定，只增加机器可读的一行总览。
