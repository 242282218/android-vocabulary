# 第 117 轮：DataStore 空词书集合写入归一化

## 审查证据

- `DataStoreSettingsRepository.settings` 读取 `selected_books` 时会把空值 fallback 到 `CET4`。
- `updateSelectedBooks(emptySet())` 原来会把空字符串写入 DataStore，虽然读侧能恢复，但持久化值本身没有表达“不允许空词书集合”的不变量。
- 第 115/116 轮已覆盖 UI 和 `toggleBook()` 的最后一本保护；直接批量更新入口仍应同样保护。

## 方案

- 方案 A：只补测试确认读侧 fallback。改动最小，但空字符串仍会被写入。
- 方案 B：写入时把空集合归一化为 `CET4`，并断言原始 DataStore 值为 `CET4`。不变量更明确，范围小。
- 方案 C：在 domain 层统一拦截空集合。能覆盖所有 repository 实现，但当前只有 DataStore 持久化实现，收益不足。

采用方案 B。

## 修改

- `core/datastore/src/main/java/com/zzz/androidvocab/core/datastore/SettingsDataStore.kt`
  - `updateSelectedBooks(emptySet())` 写入前归一化为 `setOf(BookCode.CET4)`。
  - 提取 `Set<BookCode>.toPreferenceValue()`，供批量更新和 toggle 共用。
- `core/datastore/src/test/java/com/zzz/androidvocab/core/datastore/DataStoreSettingsRepositoryTest.kt`
  - 新增 `updateSelectedBooksPersistsFallbackWhenEmpty`。
  - 断言读取值为 `CET4`，并断言底层 `selected_books` 持久化值也是 `CET4`。
