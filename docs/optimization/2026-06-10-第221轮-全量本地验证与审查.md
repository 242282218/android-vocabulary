## 当前改动判断

现有 UI 改动方向基本符合项目定位：

- 设计系统新增统一的 loading / error / filter chip / progress semantics，减少页面各自实现。
- Today、Review、Stats、Wordbook、Settings 不做营销化 hero，继续围绕学习台、复习卡、统计和设置任务流。
- 卡片圆角收敛到 12dp，错误色、禁用色、语义进度和 live region 统一到 design system。
- Review 发音按钮增加 TTS ready 状态，反馈提交中有明确不可用提示。

现有逻辑改动方向也基本符合发布前稳定性：

- App 启动不再在设置未加载时调度提醒，避免默认值误写入 WorkManager。
- 缺少通知权限时只取消提醒调度，不自动弹权限或关闭用户的持久化开关。
- 提醒调度改用 `ZonedDateTime`，覆盖 DST gap / overlap。
- 词书选择、搜索、队列排序统一产品顺序。
- 设置写入失败路径补可见错误状态，避免 ViewModel 协程直接崩溃。

## 已排除的问题

- `WordbookViewModel` 使用 `query.value` 而不是 combine 里的 debounced 参数不是误写。现有测试要求筛选或词书变化时使用尚未 debounce 完成的最新输入即时刷新。
- 当前业务代码没有散落 `Instant.now()`、`LocalDate.now()`、`LocalDateTime.now()`，时间入口仍集中在 `ClockProvider`。
- 词书 SQL 排序有 3 处 `CASE` 重复。彻底抽掉需要新增排序表、迁移字段或 SQLite 函数，当前收益不足以覆盖 schema 风险。
