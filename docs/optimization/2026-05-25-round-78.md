# 2026-05-25 持续优化第 78 轮

## 当前审查范围

本轮审查 `smoke-release-bundle.ps1` 复用 `smoke-release-apk.ps1 -SkipInstall` 时，日志是否能明确表达这是 AAB 安装后的启动复核。

## 发现

第 77 轮已经把 `smoke-release-apk.ps1 -SkipInstall` 的输出改为：

```text
[ok] installed app launch smoke passed; APK signature verification and install were skipped
```

这对直接运行 `smoke-release-apk.ps1 -SkipInstall` 是正确的。但在 `smoke-release-bundle.ps1` 中，`-SkipInstall` 是有意复用：AAB 已经通过 bundletool 安装，后续只需要检查已安装应用能启动、首屏可见且没有崩溃。

如果外层脚本不说明这一点，查看日志时仍可能误以为 APK smoke 被不完整执行。

## 完成项

`scripts/test/smoke-release-bundle.ps1`

- 在调用 `smoke-release-apk.ps1 -SkipInstall` 前增加外层说明：

```text
[info] verifying launch after bundletool install; APK signature verification and install are intentionally skipped
```

- 失败信息从：

```text
release APK smoke after bundle install failed
```

改为：

```text
installed app launch smoke after bundle install failed
```

这样 bundle smoke 日志里能清楚区分：

- bundletool 已负责 AAB 拆包安装。
- APK 子脚本这里只做已安装应用启动复核。
