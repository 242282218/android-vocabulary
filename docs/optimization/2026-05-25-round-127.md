# 2026-05-25 持续优化第 127 轮

## 当前审查范围

本轮接着第 126 轮，审查 `smoke-release-apk.ps1` 的 metadata 保存函数是否存在同类版本读取失败风险。

## 发现

`Save-ApkSmokeRunMetadata` 会读取：

```text
androidVocab.versionName
androidVocab.versionCode
Get-AndroidVocabularyReleaseApkName
```

如果 APK smoke 在临时目录、损坏仓库或缺失 `gradle.properties` 的环境中失败，catch 中再次保存 metadata 也可能二次失败，导致只输出 warning，缺少 `smoke-release-apk-run.txt`。

## 方案

- 方案 A：只在 catch 中包住 `Save-ApkSmokeRunMetadata`。改动最小，但失败时仍可能没有结构化归档。
- 方案 B：给 APK smoke metadata 保存函数使用安全取值 helper，读取失败时写 `<unresolved>`，不改变安装、签名、启动检查逻辑。

本轮采用方案 B。

## 完成项

`scripts/test/smoke-release-apk.ps1`

- 新增 `Get-ApkSmokeMetadataValue`。
- `Save-ApkSmokeRunMetadata` 中版本号和预期 APK 名称读取失败时降级为 `<unresolved>`。
- 当预期 APK 名称不可解析时：

```text
apkPathMatchesCurrentVersionedName=<unknown>
```
