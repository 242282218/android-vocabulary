## 当前审查范围

## 参考

- GitHub-hosted runners reference：GitHub-hosted Linux runners support hardware acceleration for Android SDK tools.
- GitHub Actions changelog：Linux runner 使用 Android emulator 硬件加速时，需要配置 KVM udev 规则。

## 发现

`.github/workflows/android.yml` 已经运行：

```bash
./gradlew ktlintCheck detekt testDebugUnitTest assembleDebug assembleDebugAndroidTest pixel2Api30DebugAndroidTest -Pandroid.testoptions.manageddevices.emulator.gpu=swiftshader_indirect
```

这和 README 的 CI 质量门一致，且比本地 `verify-local.ps1` 更重。

但 workflow 旧逻辑没有给 `/dev/kvm` 放开权限。`pixel2Api30DebugAndroidTest` 会启动 Gradle Managed Device；在 GitHub-hosted Linux runner 上缺少 KVM 权限时，容易在模拟器启动阶段失败或变慢。

## 完成项

`.github/workflows/android.yml`

- 在 Gradle Verify 前新增 `Enable KVM group permissions` 步骤：

```bash
echo 'KERNEL=="kvm", GROUP="kvm", MODE="0666", OPTIONS+="static_node=kvm"' | sudo tee /etc/udev/rules.d/99-kvm4all.rules
sudo udevadm control --reload-rules
sudo udevadm trigger --name-match=kvm
```

该步骤和 GitHub 官方 changelog 给出的配置一致。
