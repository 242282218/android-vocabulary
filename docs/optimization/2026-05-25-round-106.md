# 2026-05-25 持续优化第 106 轮

## 当前审查范围

本轮继续审查 `smoke-release-bundle.ps1 -ListDevices` 的委托路径，确认它是否也存在同一 PowerShell runspace 中子脚本 `throw` 绕过父脚本 exit-code 处理的问题。

## 发现

上一轮已确认：直接调用 `smoke-release-apk.ps1` 时，如果子脚本抛错，父脚本后续 `$LASTEXITCODE` 检查不可靠。

`smoke-release-bundle.ps1 -ListDevices` 仍是直接调用：

```powershell
& (Join-Path $repoRoot 'scripts\test\smoke-release-apk.ps1') -ListDevices
exit $LASTEXITCODE
```

成功时没问题；但环境缺失或子脚本抛错时，仍可能遇到相同传播问题。

## 方案

- 方案 A：保留直接调用。代码最少，但失败语义不一致。
- 方案 B：复用第 105 轮新增的 `Invoke-PowerShellScriptCommand`，用独立 PowerShell 子进程执行 `smoke-release-apk.ps1 -ListDevices`。成功时保持输出，失败时带 exit code 和最后输出。

本轮采用方案 B。

## 完成项

`scripts/test/smoke-release-bundle.ps1`

- `-ListDevices` 分支改为：

```powershell
Invoke-PowerShellScriptCommand 'list Android devices' (Join-Path $repoRoot 'scripts\test\smoke-release-apk.ps1') @('-ListDevices')
exit 0
```
