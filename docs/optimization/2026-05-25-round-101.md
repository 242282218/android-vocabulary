# 2026-05-25 持续优化第 101 轮

## 当前审查范围

本轮审查 `Save-LogcatTail` 在 adb/logcat 写 stderr 或非 0 退出时，是否仍能保存部分 logcat 输出。

## 发现

`Save-LogcatTail` 原逻辑：

```powershell
$logcatOutput = & $adb -s $ResolvedDeviceSerial logcat -d -t 1000 2>&1
$logcatOutput | Set-Content -LiteralPath $logcatPath
```

在 `$ErrorActionPreference='Stop'` 下，native 命令写 stderr 可能触发 `NativeCommandError`。本地最小实验显示，命令先写 stderr、再写 stdout、最后 exit 7 时，脚本直接进入 catch，`logcat-tail.txt` 没有生成。

## 方案

- 方案 A：和第 100 轮诊断命令一致，执行 logcat 时临时把 `$ErrorActionPreference` 调整为 `Continue`，捕获 stdout/stderr 和 exit code，最后总是尽量写入 `logcat-tail.txt`。
- 方案 B：保持 catch 包装。实现简单，但会丢失 native stderr 触发异常前后的部分输出。

本轮采用方案 A。

## 完成项

`scripts/test/verify-device.ps1`

- `Save-LogcatTail` 现在临时放宽 `$ErrorActionPreference`，捕获 logcat 输出和 exit code。
- 输出转换为字符串数组后写入 `logcat-tail.txt`。
- logcat 非 0 退出时 warning 使用捕获到的 exit code，并保留部分输出文件。
