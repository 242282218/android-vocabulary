# 2026-05-25 持续优化第 40 轮

## 当前审查范围

本轮审查数据库 mapper 层对持久化 JSON 载荷的防御性解析，重点是词条来源标记 `sourceFlagsJson` 损坏时是否会影响词条展示、搜索结果或今日队列转换。

## 发现

`Mappers.kt` 已经对 `BookCode`、`ReviewState`、`ReviewRating` 这类枚举字段做了防御性解析，但 `sourceFlagsJson` 在两个入口仍直接解析：

- `WordEntryEntity.toModel()`
- `ReviewQueueRow.toQueueItem()`

如果本地数据库中的单条 `word_entries.sourceFlagsJson` 损坏，`Json.parseToJsonElement(...).jsonArray` 会抛异常，进而影响搜索、词条详情或队列渲染。该字段只是来源标记，损坏时不应阻断核心学习闭环。

## 完成项

`core/database/src/main/java/com/zzz/androidvocab/core/database/Mappers.kt`

- 新增共享 `parseSourceFlags()`。
- 合法 JSON 数组保持原解析结果。
- 空白、坏 JSON、非数组或非字符串元素统一降级为空列表。
- `WordEntryEntity.toModel()` 和 `ReviewQueueRow.toQueueItem()` 复用该解析函数。

`core/database/src/test/java/com/zzz/androidvocab/core/database/MappersTest.kt`

- 覆盖合法 `sourceFlagsJson` 会保留来源标记。
- 覆盖实体转换遇到坏 JSON 时降级为空列表。
- 覆盖队列转换遇到坏 JSON 时降级为空列表。
